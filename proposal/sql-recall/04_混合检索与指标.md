# 混合检索与指标

> 2026-11-11 核对。数字来自当天打开的论文、榜单或官方代码。
> 总览和先导实验在 [00_总览](00_总览.md)。

文献支持的是分工，不是替换。显式谓词交给数据库，语义匹配交给检索或模型谓词。STaRK 上打过 ada-002 的方法都还在检索：AvaTaR 的 Amazon Hit@1 49.87，KAR 合成集 54.20、人工留出集 61.73，MoR 52.19。HybGRAG 没有 Amazon 数字。SPARK（[arXiv 2602.16964](https://arxiv.org/abs/2602.16964)）让模型写 Cypher 再在 Neo4j 里执行，合成 Amazon 上 Recall@20 是 53.95，BM25 是 53.77，打平；作者说约束抽取和过滤占错误的 30%–36%。没有经过评审的、用 SQL 候选集换掉 STaRK 检索器的结果。

向量检索在约束上的失败，和 SQL 对得上的是「约束已经变成列或谓词」的那一类：

| 论文 | 失败的是什么 | 数字 |
|---|---|---|
| [NevIR](https://arxiv.org/html/2305.07614v2) | 双编码器处理否定 | 成对准确率没有一个双编码器超过 12%，多数在 5%–10%。随机是 25% |
| [NumConQ](https://doi.org/10.26599/BDMA.2025.9020047) | 身高、体重、年龄等数值谓词 | 数值属性上的一致性平均 16.3%，非数值属性 73.64%。最好的 BGE-M3，Recall@10 40.37% |
| [QUEST](https://aclanthology.org/2023.acl-long.784/)，ACL 2023 | 隐式的交、并、差 | T5-Large 双编码器 Recall@100 0.476，宏召回只有 0.142 |
| [FollowIR](https://aclanthology.org/2025.naacl-long.597.pdf)，NAACL 2025 | 检索模型把指令当关键词 | 小于 3B、以及按检索器训练的模型，p-MRR 上普遍失败 |
| ACORN，SIGMOD 2024 | 显式元数据上的过滤近似搜索 | 这是速度结果：0.9 召回下查询速度高 2–1,000 倍。效果上的失败见 [召回 baseline](02_召回baseline.md) 里过滤近似搜索那一段 |

「适合家庭」或「不要太甜」如果还在评论文本里，SUQL 的 `answer()` 说明模型调用去不掉。BRIGHT（ICLR 2025）则说明不能把每条难查询都路由到 SQL：BM25 的平均 nDCG@10 是 14.5，最好的嵌入平均是 24.3，提升来自对候选做推理，最多 +12.2。

[Text2VectorSQL](https://arxiv.org/html/2506.23071) 是同一分工的警告：用 SQL 后过滤向量结果，尤其是连接，相对过滤向量搜索可以丢掉 30% 以上的正确结果。所以先导实验要同时报「SQL 超集再排序」和「先向量再 SQL 过滤」。

指标直接借用，不新造指数。一个人、公开数据、有 API 预算，用户研究放不进主结果。

| 要证明的 | 用什么 | 定义 | 出处 |
|---|---|---|---|
| 确定性 | TARr@N、TARa@N | 温度 0 下 N 次运行里，原始字符串相同的比例，以及解析后答案相同的比例。原文里准确率摆动最大 15%，最好和最差相差最大 70% | [arXiv 2408.04667](https://arxiv.org/html/2408.04667) |
| 确定性 | 候选集的 Jaccard；Kendall's tau | 两次 top-k 的交集除以并集；两个排序的秩相关。SQL 字符串相同，结果集就应该相同，剩下的方差来自解析 | [ReproRAG，arXiv 2509.18869](https://arxiv.org/html/2509.18869) |
| 确定性 | 改写距离 | 1 减去两次检索集合的重叠。五个编码器、2200 万到 80 亿参数，HotpotQA、FEVER、SQuAD 2.0 上这个距离停在 32%–50% | [UncertainNLP 2026](https://aclanthology.org/2026.uncertainlp-main.34.pdf) |
| 约束满足 | 条件匹配率 CMR | 推荐物品里满足所述条件的比例。Precision 和 Recall 量不到这个 | RecBench+ |
| 约束满足 | PassRate、PassRate_feas | 名单通过确定性校验器的用户比例；分母可以限制为存在可行名单的用户。MovieLens-100K 上，一次生成的大模型是 0.000，校验过的系统是 0.985（551 个可行用户），NDCG@10 从 0.424 到 0.403 | [PCN-Rec，arXiv 2601.09771](https://arxiv.org/html/2601.09771) |
| 约束满足 | 数值一致性 | 取回的证据里，数值属性和谓词一致的比例 | NumConQ，见上表 |
| 可解释 | 执行即忠实 | 模型给出符号链，确定性求解器给出答案。对这篇，SQL 文本是忠实的，当且仅当返回的候选正好是它的执行结果 | Faithful CoT，IJCNLP-AACL 2023 |
| 可解释 | 见证元组 | 一条输出元组由哪些输入元组证明。推荐里，每个返回的物品都要能指出满足查询的见证行。不需要新的分数 | Buneman 等对 why-provenance 的表述 |

可模拟性（给解释之后，另一个模型或人能否预测系统的输出）是标准指标，但要第二个模型或用户研究。引用，不做主实验。自然语言用户画像的可审视性是 ACL 2024 长文 [2024.acl-long.753](https://aclanthology.org/2024.acl-long.753/)，用户能读、能改画像，推荐从画像算出来。一条展示出来、能改的 `WHERE` 是这件事的形式语言版本，可以放进附录的探针，不单独成贡献。

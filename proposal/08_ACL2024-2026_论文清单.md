# ACL 2024–2026：Agent × RecSys 论文清单

> 2026-10-21。来源是 ACL Anthology 官方 XML，不是二次综述。
> 范围：2024、2025、2026 的主会 long / short、Industry、Demo，以及 Findings 里 venue 为 ACL 的卷。不含 NAACL、EMNLP、EACL，不含 tutorials 和 student research workshop。
> 这份清单不判断创新性。第 1 节是建议通读的推荐、对话推荐、购物 agent、推荐向用户模拟。第 2 节是相邻工作。第 3 节是标题撞上关键词、但不是这个方向的论文，列出来是为了说明没有悄悄删掉。

主清单 73 篇，相邻 31 篇，排除 23 篇。

收录进第 1 节的规则：标题含 recommend / recommender / shopping / e-commerce / user simulat / next-item / product search / collaborative filtering，并且任务是推荐、对话推荐、购物或推荐场景下的用户模拟。

「Agent」列：标题里出现 agent，或只在摘要里出现。很多推荐论文不用 agent 这个词。

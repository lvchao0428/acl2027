# 消除 LLM 推荐系统中的域外推荐：一个统一视角
> 来源文件：Eliminating Out-of-Domain Recommendations in LLM-based Recommender Systems - A Unified View.pdf
## 英文原文摘要（Original Abstract）
Recommender systems based on Large Lan-guage Models (LLMs) are often plagued by hallucinations of out-of-domain (OOD) items. To address this, we propose RecLM, a uni-fied framework that bridges the gap between retrieval and generation by instantiating three grounding paradigms under a single architec-ture: embedding-based retrieval, constrained generation over rewritten item titles, and dis-crete item-tokenizer generation. Using the same backbone LLM and prompts, we system-atically compare these three views on public benchmarks. RecLM strictly eradicates OOD recommendations (OOD@10 = 0) across all variants, and the constrained generation vari-ants RecLM-cgen and RecLM-token achieve overall state-of-the-art accuracy compared to both strong ID-based and LLM-based baselines. Our unified view provides a systematic basis for comparing three distinct paradigms to re-duce item hallucinations, offering a practical framework to facilitate the application of LLMs to recommendation tasks. Source code is at https://github.com/microsoft/RecAI.
## 中文翻译（Chinese Translation）
基于大语言模型（LLM）的推荐系统常受困于“域外（OOD）商品”幻觉。为此，我们提出 RecLM，一个统一框架，在单一架构下实例化三种落地（grounding）范式，弥合检索与生成之间的鸿沟：基于嵌入的检索、基于改写商品标题的受限生成，以及离散商品 tokenizer 生成。使用同一骨干 LLM 与提示，我们在公开基准上系统比较这三种视角。RecLM 在所有变体中彻底消除了域外推荐（OOD@10 = 0），其中受限生成变体 RecLM-cgen 与 RecLM-token 相对强 ID 基线与 LLM 基线取得了整体最优准确率。我们的统一视角为比较三种不同范式以减少商品幻觉提供了系统依据，也为 LLM 落地推荐任务提供了实用框架。

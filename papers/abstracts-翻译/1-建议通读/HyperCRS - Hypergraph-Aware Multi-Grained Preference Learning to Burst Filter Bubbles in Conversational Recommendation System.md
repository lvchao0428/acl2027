# HyperCRS: Hypergraph-Aware Multi-Grained Preference Learning to Burst Filter Bubbles in Conversational Recommendation System
> 来源文件：HyperCRS - Hypergraph-Aware Multi-Grained Preference Learning to Burst Filter Bubbles in Conversational Recommendation System.pdf

## 英文原文摘要（Original Abstract）

The filter bubble is a notorious issue in Recommender Systems (RSs), characterized by users being confined to a limited corpus of information or content that strengthens and amplifies their pre-established preferences and beliefs. Most existing methods primarily aim to analyze filter bubbles in the relatively static recommendation environment. Nevertheless, the filter bubble phenomenon continues to exacerbate as users interact with the system over time. To address these issues, we propose a novel paradigm, Hypergraph-Aware Multi-Grained Preference Learning to Burst Filter Bubbles in Conversational Recommendation System (HyperCRS), aiming to burst filter bubbles by learning multi-grained user preferences during the dynamic user-system interactions via natural language conversations. HyperCRS develops Multi-Grained Hypergraph (user-, item-, and attribute-grained) to explore diverse relations and capture highorder connectivity. It employs HypergraphEmpowered Policy Learning, which includes Multi-Grained Preference Modeling to model user preferences and Preference-based Decision Making to disrupt filter bubbles during user interactions. Extensive results on four publicly CRS-based datasets show that HyperCRS achieves new state-of-the-art performance, and the superior of bursting filter bubbles in the CRS.

## 中文翻译（Chinese Translation）

过滤气泡（filter bubble）是推荐系统中的一个著名问题，表现为用户被局限在有限的信息或内容中，从而强化并放大其既有的偏好与信念。多数现有方法主要在相对静态的推荐环境下分析过滤气泡。然而，随着用户与系统长期交互，过滤气泡现象持续恶化。针对这些问题，我们提出一个新范式 Hypergraph-Aware Multi-Grained Preference Learning to Burst Filter Bubbles in Conversational Recommendation System（HyperCRS），旨在通过在自然语言对话驱动的动态用户-系统交互中学习多粒度用户偏好来戳破过滤气泡。HyperCRS 构建了多粒度超图（用户粒度、商品粒度、属性粒度），以探索多样关系并捕获高阶连通性；并采用超图赋能的策略学习，包括多粒度偏好建模（对用户偏好进行建模）和基于偏好的决策（在用户交互过程中打破过滤气泡）。在四个公开 CRS 数据集上的大量结果表明：HyperCRS 取得了新的最先进性能，并在 CRS 中戳破过滤气泡方面表现更优。代码见 https://github.com/zysensmile/HyberCRS。

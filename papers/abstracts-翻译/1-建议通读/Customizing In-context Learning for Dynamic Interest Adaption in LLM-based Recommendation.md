# 定制上下文学习以实现 LLM 推荐中的动态兴趣适配
> 来源文件：Customizing In-context Learning for Dynamic Interest Adaption in LLM-based Recommendation.pdf
## 英文原文摘要（Original Abstract）
Periodically updating Large Language Model (LLM)-based recommender systems to adapt to dynamic user interests—as is done for tra-ditional ones—is impractical due to high train-ing costs. This work explores the possibility of achieving interest adaptation without any model-level updates via In-context Learning (ICL), which enables adaptation through few- shot examples within input prompts. Using recent interactions as ICL few-shot examples, LLMs can directly learn the new interest in prompt without needing model updates. While pre-trained LLMs possess strong in-context learning capabilities, these are often diminished after task-specific fine-tuning in recommender systems, and the original ICL mechanism lacks specialization for recommendation tasks. To ad-dress this, we propose RecICL, a framework for recommendation-oriented ICL. It performs tun-ing in an ICL manner, structuring new-interest interactions as few-shot examples to capture dynamic interests during data fitting. Exten-sive experiments across multiple benchmarks demonstrate RecICL’s superior performance, achieving better results without model updates. Our implementation is publicly available at https://github.com/ym689/rec_icl.
## 中文翻译（Chinese Translation）
像传统推荐系统那样周期性更新基于大语言模型（LLM）的推荐系统以适配动态用户兴趣，因训练成本高昂而并不现实。本文探索在完全不做模型级更新的前提下，通过上下文学习（ICL）实现兴趣适配的可能性——ICL 仅靠输入提示中的少量示例即可完成适配。将近期交互作为 ICL 少样本示例，LLM 可直接在提示中学习新兴趣，而无需更新模型。虽然预训练 LLM 具备强大的上下文学习能力，但在推荐系统的任务专用微调后这种能力往往被削弱，且原始 ICL 机制缺乏对推荐任务的专门化。为此，我们提出 RecICL，一个面向推荐的 ICL 框架。它以 ICL 方式进行调优，把新兴趣交互构造成少样本示例，在数据拟合过程中捕捉动态兴趣。在多个基准上的大量实验证明 RecICL 性能优异，无需模型更新即可取得更好结果。

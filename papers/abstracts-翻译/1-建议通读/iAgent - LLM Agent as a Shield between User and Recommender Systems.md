# iAgent: LLM Agent as a Shield between User and Recommender Systems
> 来源文件：iAgent - LLM Agent as a Shield between User and Recommender Systems.pdf

## 英文原文摘要（Original Abstract）

Traditional recommender systems usually take the user-platform paradigm, where users are directly exposed under the control of the platform’s recommendation algorithms. However, the defect of recommendation algorithms may put users in very vulnerable positions under this paradigm. First, many sophisticated models are often designed with commercial objectives in mind, focusing on the platform’s benefits, which may hinder their ability to protect and capture users’ true interests. Second, these models are typically optimized using data from all users, which may overlook individual user’s preferences. Due to these shortcomings, users may experience several disadvantages under the traditional user-platform direct exposure paradigm, such as lack of control over the recommender system, potential manipulation by the platform, echo chamber effects, or lack of personalization for less active users due to the dominance of active users during collaborative learning. Therefore, there is an urgent need to develop a new paradigm to protect user interests and alleviate these issues. Recently, some researchers have introduced LLM agents to simulate user behaviors, these approaches primarily aim to optimize platform-side performance, leaving core issues in recommender systems unresolved. To address these limitations, we propose a new user-agent-platform paradigm, where agent serves as the protective shield between user and recommender system that enables indirect exposure. To this end, we first construct four recommendation datasets, denoted as INSTRUCTREC, along with user instructions for each record. To understand user’s intention, we design an Instruction-aware Agent (iAgent) capable of using tools to acquire knowledge from external environments. Moreover, we introduce an Individual Instruction-aware Agent (i2Agent), which incorporates a dynamic memory mechanism to optimize from individual feedback. Results on four INSTRUCTREC datasets demonstrate that i2Agent consistently achieves an average improvement of 16.6% over SOTA baselines across ranking metrics. Moreover, i2Agent mitigates echo chamber effects and effectively alleviates the model bias in disadvantaged users (less-active), serving as a shield between user and recommender systems.

## 中文翻译（Chinese Translation）

传统推荐系统通常采用"用户-平台"范式，用户直接暴露在平台推荐算法的控制之下。然而，在这种范式下，推荐算法的缺陷可能让用户处于非常脆弱的位置。第一，许多复杂模型在设计时往往以商业目标为导向，关注平台利益，这可能损害其保护和捕获用户真实兴趣的能力。第二，这些模型通常用所有用户的数据进行优化，可能忽略个体用户的偏好。由于这些不足，用户在传统的"用户-平台"直接暴露范式下可能遭遇若干劣势：对推荐系统缺乏掌控感、被平台潜在操纵、回声室（echo chamber）效应，以及由于协同学习中活跃用户占主导而使不活跃用户得不到个性化。因此，亟需发展一种新范式来保护用户利益并缓解这些问题。近来已有研究者引入 LLM 智能体来模拟用户行为，但这些方法主要目标是优化平台侧性能，并未解决推荐系统中的核心问题。为克服这些局限，我们提出一种新的"用户-智能体-平台"范式，其中智能体作为用户与推荐系统之间的保护盾（protective shield），实现间接暴露。为此，我们首先构建了四个推荐数据集（记为 INSTRUCTREC），并为每条记录附带用户指令。为理解用户意图，我们设计了一个指令感知智能体（Instruction-aware Agent, iAgent），能够使用工具从外部环境获取知识；此外，我们还引入了个体指令感知智能体（i2Agent），它融入动态记忆机制，从个体反馈中进行优化。在四个 INSTRUCTREC 数据集上的结果表明，i2Agent 在排序指标上相对 SOTA 基线平均提升 16.6%；并且 i2Agent 能够缓解回声室效应，有效减轻处于弱势的用户（不活跃用户）所受的模型偏置，充当用户与推荐系统之间的保护盾。

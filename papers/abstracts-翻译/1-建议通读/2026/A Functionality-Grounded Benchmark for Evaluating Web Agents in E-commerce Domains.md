# 基于功能落地的电子商务领域 Web Agent 评估基准
> 来源文件：A Functionality-Grounded Benchmark for Evaluating Web Agents in E-commerce Domains.pdf
> 发表年份：2026
> 单位：Amazon；Pennsylvania State University
## 英文原文摘要（Original Abstract）
Web agents have shown great promise in per-forming many tasks on e-commerce websites. To assess their capabilities, several benchmarks have been introduced. However, current bench-marks in the e-commerce domain face two major problems. First, they primarily focus on product search tasks (e.g., "Find an Ap-ple Watch"), failing to capture the broader range of functionalities offered by real-world e-commerce services such as Amazon, including account management and gift card operations. Second, existing benchmarks typically evalu-ate whether the agent completes the user query, but ignore the potential risks involved. In prac-tice, web agents can make unintended changes that negatively impact the user’s account or status. For instance, an agent might purchase the wrong item, delete a saved address, or in-correctly configure an auto-reload setting. To address these gaps, we propose a new bench-mark called Amazon-Bench. To generate user queries that cover a broad range of tasks, we propose a data generation pipeline that lever-ages webpage content and interactive elements (e.g., buttons, check boxes) to create diverse, functionality-grounded user queries covering tasks such as address management, wishlist management, and brand store following. To enhance agent evaluation, we propose an au-tomated evaluation framework that assesses both the performance and safety of web agents. We systematically evaluate various agents, find-ing that current agents struggle with complex queries and pose safety risks. These results highlight the need for developing more robust and reliable web agents. 1
## 中文翻译（Chinese Translation）
Web Agent（网页智能体）在完成电商网站上的各类任务方面展现出广阔前景。为评估其能力，学界已提出若干基准。然而，当前电商领域的基准存在两个突出问题：其一，它们主要聚焦商品搜索任务（例如“找一块 Apple Watch”），未能覆盖真实电商服务（如 Amazon）所提供的更广泛功能，包括账户管理、礼品卡操作等；其二，现有基准通常只评估智能体是否完成了用户查询，却忽视了其中潜在的风险。在实际中，Web Agent 可能做出非预期的改动，对用户账户或状态造成负面影响——例如买错商品、删除已保存的地址，或错误配置自动充值设置。针对这些不足，本文提出一个新基准 Amazon-Bench。为生成覆盖广泛任务的用户查询，我们设计了一套数据生成流水线，利用网页内容与交互元素（如按钮、复选框）来构造多样化、以功能为落地依据的用户查询，覆盖地址管理、心愿单管理、品牌店铺关注等任务。为强化智能体评估，我们提出一个自动化评估框架，同时衡量 Web Agent 的性能与安全性。我们系统地评测了多种智能体，发现当前智能体在复杂查询上表现不佳，且存在安全风险。这些结果凸显了开发更稳健、更可靠 Web Agent 的必要性。

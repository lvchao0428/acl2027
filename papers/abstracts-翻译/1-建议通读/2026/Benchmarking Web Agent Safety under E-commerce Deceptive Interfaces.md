# 电商欺骗性界面下的 Web Agent 安全基准评测
> 来源文件：Benchmarking Web Agent Safety under E-commerce Deceptive Interfaces.pdf
> 发表年份：2026
> 单位：University of Liverpool and Eindhoven University of Technology；University of Technology Sydney
## 英文原文摘要（Original Abstract）
As autonomous web agents are increasingly deployed to perform real-world tasks, ensur-ing their safety has become a critical concern. In this work, we study web agent behavior under realistic deceptive interfaces in the e-commerce domain. We introduce WebDecept, a lightweight and configurable plugin frame-work that enables controlled injection of decep-tive interface patterns into existing web environ-ments. Using WebDecept, we instantiate seven deceptive patterns commonly observed on the open web, including targeted advertisements, domain redirection, and shopping manipulation. By injecting these patterns into the frontend during task execution, we perform controlled evaluation of multiple multimodal web agents. Our results show that current web agents are highly susceptible to multiple classes of de-ceptive interfaces, and that prompt-based con-straints are often insufficient to mitigate these failures. We further analyze how the design choices of deceptive patterns influence the suc-cess of such manipulations. These findings highlight safety challenges that should be ad-dressed as web agents are scaled toward real-world deployment.
## 中文翻译（Chinese Translation）
随着自主 Web Agent 越来越多地被部署去执行真实任务，确保其安全已成为关键议题。本文研究 Web Agent 在电商领域真实欺骗性界面下的行为。我们提出 WebDecept，一个轻量、可配置的插件框架，能够向现有 Web 环境中受控地注入欺骗性界面模式。借助 WebDecept，我们实例化了七种在开放网络上常见的欺骗模式，包括定向广告、域名跳转和购物操纵。通过在任务执行期间向前端注入这些模式，我们对多个多模态 Web Agent 进行了受控评估。结果表明，当前 Web Agent 对多类欺骗性界面高度脆弱，而基于提示词的约束往往不足以缓解这些失效。我们进一步分析了欺骗模式的设计选择如何影响此类操纵的成功率。这些发现凸显了在 Web Agent 走向真实部署时必须应对的安全挑战。

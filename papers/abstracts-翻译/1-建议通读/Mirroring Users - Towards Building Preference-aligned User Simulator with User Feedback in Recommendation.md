# Mirroring Users: Towards Building Preference-aligned User Simulator with User Feedback in Recommendation
> 来源文件：Mirroring Users - Towards Building Preference-aligned User Simulator with User Feedback in Recommendation.pdf

## 英文原文摘要（Original Abstract）

User simulation is increasingly vital to develop and evaluate recommender systems (RSs). While Large Language Models (LLMs) offer promising avenues to simulate user behavior, they often struggle with the absence of specific task alignment required for RSs and the efficiency demands of large-scale simulation. A vast yet underutilized resource for enhancing this alignment is the extensive user feedback inherent in RSs, but leveraging it is challenging due to its ambiguity, noise and massive volume, which hinders efficient preference alignment. To overcome these hurdles, we introduce a novel data construction framework that leverages user feedback in RSs with advanced LLM capabilities to generate high-quality simulation data. Our framework unfolds in two key phases: (1) using LLMs to generate decisionmaking processes as explanatory rationales on simulation samples, thereby reducing ambiguity; and (2) data distillation based on uncertainty estimation and behavior sampling to efficiently filter the most informative, denoised samples. Accordingly, we fine-tune lightweight LLMs, as user simulators, using such highquality dataset with corresponding decisionmaking processes. Extensive experiments confirm that our framework significantly boosts the alignment with human preferences and the in-domain reasoning capabilities of the finetuned LLMs, providing more insightful and interpretable signals for RS interaction. We believe our work, together with publicly available developed framework, high-quality mixeddomain dataset, and fine-tuned LLM checkpoints, will advance the RS community and offer valuable insights for broader human-centric AI research.

## 中文翻译（Chinese Translation）

用户模拟对推荐系统（RS）的开发与评估愈发重要。虽然大语言模型（LLM）为模拟用户行为提供了有前景的路径，但它们常常难以满足 RS 所需的特定任务对齐，以及大规模模拟的效率要求。增强这种对齐的一个庞大却未充分利用的资源，是 RS 中固有的大量用户反馈；但由于其模糊性、噪声和海量规模，利用起来颇具挑战，阻碍了高效的偏好对齐。为克服这些障碍，我们提出一个新颖的数据构建框架，利用 RS 中的用户反馈与先进的 LLM 能力来生成高质量模拟数据。我们的框架分两个关键阶段展开：(1) 用 LLM 在模拟样本上生成决策过程作为解释性 rationale（理由），从而降低模糊性；(2) 基于不确定性估计与行为采样进行数据蒸馏，高效过滤出最具信息量、去噪后的样本。相应地，我们用这种带决策过程的高质量数据集，微调轻量 LLM 作为用户模拟器。大量实验证实，我们的框架显著提升了微调 LLM 与人类偏好的对齐程度以及域内推理能力，为 RS 交互提供了更有洞见、可解释的信号。我们相信，本工作连同公开的框架、高质量的混合领域数据集以及微调后的 LLM 检查点，将推动 RS 社区发展，并为更广义的以人为中心的 AI 研究提供有价值的洞见。代码见 https://github.com/Joinn99/UserMirrorer。

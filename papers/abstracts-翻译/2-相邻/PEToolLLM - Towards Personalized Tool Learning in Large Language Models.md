# PEToolLLM: Towards Personalized Tool Learning in Large Language Models
> 来源文件：PEToolLLM - Towards Personalized Tool Learning in Large Language Models.pdf
## 英文原文摘要（Original Abstract）
Tool learning has emerged as a promising direction by extending Large Language Models' (LLMs) capabilities with external tools. Existing tool learning studies primarily focus on the general-purpose tool-use capability, which addresses explicit requirements in user instructions. However, they overlook the importance of personalized tool-use capability, leading to an inability to meet personalized user needs. To address the limitation, we first formulate the task of personalized tool learning, which integrates user's interaction history towards personalized tool usage. To fill the gap of missing benchmarks, we construct PEToolBench, featuring diverse user preferences reflected in interaction history under three distinct personalized settings, and encompassing a wide range of tool-use scenarios. Moreover, we propose a framework PEToolLLaMA to adapt LLMs to the personalized tool learning task, which is trained through supervised fine-tuning and direct preference optimization. Extensive experiments on PEToolBench demonstrate the superiority of PEToolLLaMA over existing LLMs. We release our code and data at https://github.com/travis-xu/PEToolBench.
## 中文翻译（Chinese Translation）
工具学习通过外部工具扩展大语言模型（LLM）能力，已成为一个颇具前景的方向。现有工具学习研究主要关注通用工具调用能力，即满足用户指令中的显式需求；然而它们忽视了个性化工具调用能力的重要性，导致无法满足用户的个性化需求。为弥补这一不足，我们首先形式化定义了"个性化工具学习"任务——将用户交互历史融入工具使用以实现个性化工具调用。为填补基准缺失的空白，我们构建了 PEToolBench，该基准在三种不同个性化设定下通过交互历史反映多样化用户偏好，并涵盖广泛的工具使用场景。此外，我们提出 PEToolLLaMA 框架，通过监督微调（SFT）与直接偏好优化（DPO）训练 LLM 以适配个性化工具学习任务。在 PEToolBench 上的大量实验表明，PEToolLLaMA 显著优于现有 LLM。代码与数据已发布于 https://github.com/travis-xu/PEToolBench。

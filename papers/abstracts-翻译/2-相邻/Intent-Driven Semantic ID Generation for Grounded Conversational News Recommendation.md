# Intent-Driven Semantic ID Generation for Grounded Conversational News Recommendation
> 来源文件：Intent-Driven Semantic ID Generation for Grounded Conversational News Recommendation.pdf
## 英文原文摘要（Original Abstract）
Conversational news recommendation requires grounding each suggestion in a rapidly evolv- ing article corpus while addressing implicit user intents that lack explicit retrievable keywords. To characterize this scenario, we identify 6 intent types from production dialogues: five are implicit and pose fundamental challenges to standard RAG pipelines, forming a critical retrieve-first bottleneck. To address these is- sues, we introduce intent-driven Semantic ID (SID) generation under a Generate-then- Match paradigm. With two-stage training that consists of multi-task SID alignment and GPT- 4 Chain-of-Thought distillation, an LLM maps diverse intents to hierarchical SID prefixes, which are then fuzzy-matched to the current news pool to guarantee fully grounded recom- mendations. Profile-Aware Dual-Signal Rea- soning (PADR) further enables cold-start users to obtain valid recommendations using only profiles. On a mainstream Chinese news plat- form, our 7B model achieves 0% hallucina- tion and 12.4% L1 match in the 152K open- generation SID space (4× random baseline). It matches GPT-4+Hybrid RAG on L1 while surpassing it on finer-grained metrics (L2 2×, Category +1.2pp) at ∼100× lower cost. Cold- start users, where existing baselines score 0%, achieve 18.0% L1 (6× random), the highest among all user groups.

## 中文翻译（Chinese Translation）
对话式新闻推荐需要将每一条建议锚定在快速更新的文章语料库中，同时处理缺乏显式可检索关键词的隐式用户意图。为刻画这一场景，我们从真实生产对话中识别出 6 类意图：其中 5 类为隐式意图，对标准 RAG 流水线构成根本性挑战，形成了关键的"先检索"瓶颈。为解决这些问题，我们在"先生成后匹配"（Generate-then-Match）范式下提出了意图驱动的语义 ID（Semantic ID, SID）生成方法。通过多任务 SID 对齐和 GPT-4 思维链蒸馏两阶段训练，LLM 将多样化意图映射为层级化的 SID 前缀，再与当前新闻池进行模糊匹配，以确保推荐完全基于真实内容。画像感知双信号推理（PADR）进一步使冷启动用户仅靠画像即可获得有效推荐。在某主流中文新闻平台上，我们的 7B 模型在 152K 开放生成 SID 空间中实现了 0% 幻觉率和 12.4% 的 L1 匹配率（随机基线的 4 倍）。它在 L1 指标上与 GPT-4+混合 RAG 相当，在更细粒度指标上则超越后者（L2 为 2 倍，类别 +1.2 个百分点），而成本降低约 100 倍。在现有基线得分为 0% 的冷启动用户群体中，我们的方法达到了 18.0% 的 L1（随机基线的 6 倍），为所有用户群体中最高。

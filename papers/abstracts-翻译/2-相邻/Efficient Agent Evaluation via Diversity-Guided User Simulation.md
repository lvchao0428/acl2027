# Efficient Agent Evaluation via Diversity-Guided User Simulation
> 来源文件：Efficient Agent Evaluation via Diversity-Guided User Simulation.pdf
## 英文原文摘要（Original Abstract）
Large language models (LLMs) are increas- ingly deployed as customer-facing agents, yet evaluating their reliability remains challeng- ing due to stochastic, multi-turn interactions. Current evaluation protocols rely on linear Monte Carlo rollouts of complete agent–user conversations to estimate success. However, this approach is computationally inefficient, requiring re-processing identical conversation prefixes, and often fails to expose deep fail- ure modes hidden behind rare user behav- iors. In this work, we introduce DIVERT (Diversity-Induced EValuation via branching of Trajectories), an efficient, snapshot-based, coverage-guided user simulation framework for systematic exploration of diverse agent–user interactions. DIVERT snapshots the full agent–environment state at critical junctions and resumes execution from these points. By reusing shared conversation prefixes, it avoids regenerating identical early turns, reducing to- ken cost. From each junction, it branches with targeted, diversity-inducing user responses, en- abling directed exploration of alternative user responses. As a result, the evaluation is steered toward unexplored semantic paths and rare in- teraction states efficiently. Empirical experi- ments show that our framework both improves failure discovery efficiency compared to stan- dard linear rollout protocols.

## 中文翻译（Chinese Translation）
大语言模型（LLM）越来越多地被部署为面向客户的智能体，但由于其交互具有随机性和多轮性，评估其可靠性仍然充满挑战。当前的评估协议依赖于完整智能体—用户对话的线性蒙特卡洛抽样（Monte Carlo rollout）来估计成功率。然而，这种方法计算效率低下，需要重复处理相同的对话前缀，且往往无法暴露隐藏在稀有用户行为背后的深层失效模式。本文提出 DIVERT（基于轨迹分支的多样性诱导评估），这是一个高效的、基于快照的、覆盖引导的用户模拟框架，用于系统性地探索多样化的智能体—用户交互。DIVERT 在关键节点对完整的智能体—环境状态进行快照，并从这些节点恢复执行。通过复用共享的对话前缀，它避免了重新生成相同的早期轮次，从而降低 token 开销。从每个节点出发，它以有针对性的、多样性诱导的用户响应进行分支，实现对备选用户响应的定向探索。由此，评估过程被高效引导至未探索的语义路径和稀有交互状态。实证实验表明，与标准的线性 rollout 协议相比，该框架同时提升了失效发现效率。

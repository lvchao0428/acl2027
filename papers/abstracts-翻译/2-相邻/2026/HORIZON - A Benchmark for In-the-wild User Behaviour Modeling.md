# HORIZON - A Benchmark for In-the-wild User Behaviour Modeling
> 来源文件：HORIZON - A Benchmark for In-the-wild User Behaviour Modeling.pdf
> 发表年份：2026
> 单位：Microsoft Research；University of California, Berkeley；Microsoft
## 英文原文摘要（Original Abstract）
User behavior in the real world is diverse, cross- domain, and spans long time horizons. Exist- ing user modeling benchmarks however remain narrow, focusing mainly on short sessions and next-item prediction within a single domain. Such limitations hinder progress toward robust and generalizable user models. We present HORIZON a new benchmark that reformulates user modeling along three axes i.e. dataset, task, and evaluation. Built from a large-scale, cross- domain reformulation of Amazon Reviews, HORIZON covers 54M users and 35M items, en- abling both pretraining and realistic evaluation of models in heterogeneous environments. Un- like prior benchmarks, it challenges models to generalize across domains, users, and time, moving beyond standard missing-positive pre- diction in the same domain. We propose new tasks and evaluation setups that better reflect real-world deployment scenarios. These in- clude temporal generalization, sequence-length variation, and modeling unseen users, with met- rics designed to assess general user behavior understanding rather than isolated next-item prediction. We benchmark popular sequen- tial recommendation architectures alongside LLM-based baselines that leverage long-term interaction histories. Our results highlight the gap between current methods and the demands of real-world user modeling, while establish- ing HORIZON as a foundation for research on temporally robust, cross-domain, and general- purpose user models.

## 中文翻译（Chinese Translation）
现实世界中的用户行为是多样化的、跨领域的，且跨越很长的时间跨度。然而，现有的用户建模基准仍然较为狭窄，主要聚焦于短会话和单领域内的下一物品预测。这些局限阻碍了稳健、可泛化用户模型的发展。本文提出 HORIZON，这是一个从数据集、任务和评估三个维度重新定义用户建模的新基准。HORIZON 基于对 Amazon Reviews 的大规模跨领域重构，覆盖 5400 万用户和 3500 万物品，支持在异构环境中进行预训练和真实评估。与以往基准不同，它要求模型跨领域、跨用户、跨时间进行泛化，超越了传统的同领域缺失正样本预测任务。我们提出了更贴近真实部署场景的新任务和评估设置，包括时间泛化、序列长度变化以及未见用户建模，并设计了旨在评估通用用户行为理解能力而非孤立下一物品预测的指标。我们对主流序列推荐架构以及利用长期交互历史的 LLM 基线进行了基准测试。结果揭示了当前方法与真实用户建模需求之间的差距，同时确立 HORIZON 作为时间稳健、跨领域、通用用户模型研究的基础平台。

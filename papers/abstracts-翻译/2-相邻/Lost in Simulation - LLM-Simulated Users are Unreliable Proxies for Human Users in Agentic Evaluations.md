# Lost in Simulation - LLM-Simulated Users are Unreliable Proxies for Human Users in Agentic Evaluations
> 来源文件：Lost in Simulation - LLM-Simulated Users are Unreliable Proxies for Human Users in Agentic Evaluations.pdf
## 英文原文摘要（Original Abstract）
Agentic benchmarks increasingly rely on LLM- simulated users to scalably evaluate agent per- formance, yet the robustness, validity, and fairness of this approach remain unexamined. Through a user study with participants across the United States, India, Kenya, and Nigeria, we investigate whether LLM-simulated users serve as reliable proxies for real human users in evaluating agents on τ-Bench retail tasks. We find that user simulation lacks robustness, with agent success rates varying up to 9 per- centage points across different user LLMs. Fur- thermore, evaluations using simulated users ex- hibit systematic miscalibration, underestimat- ing agent performance on challenging tasks and overestimating it on moderately difficult ones. African American Vernacular English (AAVE) speakers experience consistently worse success rates and calibration errors than Standard Amer- ican English (SAE) speakers, with disparities compounding significantly with age. We also find simulated users to be a differentially effec- tive proxy for different populations, performing worst for AAVE and Indian English speakers. Additionally, simulated users introduce con- versational artifacts and surface different fail- ure patterns than human users. These findings demonstrate that current evaluation practices risk misrepresenting agent capabilities across diverse user populations and may obscure real- world deployment challenges.

## 中文翻译（Chinese Translation）
智能体（Agentic）基准越来越依赖 LLM 模拟用户来大规模评估智能体性能，但这种方法的稳健性、有效性和公平性尚未得到检验。通过一项覆盖美国、印度、肯尼亚和尼日利亚参与者的用户研究，我们考察了在 τ-Bench 零售任务上，LLM 模拟用户是否能作为真实人类用户的可靠代理来评估智能体。我们发现用户模拟缺乏稳健性：不同用户 LLM 对应的智能体成功率差异高达 9 个百分点。此外，使用模拟用户的评估存在系统性失准——在困难任务上低估智能体性能，在中等难度任务上则高估。非裔美国人 Vernacular 英语（AAVE）使用者的成功率和校准误差始终比标准美式英语（SAE）使用者更差，且差距随年龄显著扩大。我们还发现模拟用户对不同人群的代理效果存在差异，对 AAVE 和印度英语使用者表现最差。此外，模拟用户会引入对话伪影，并暴露出与人类用户不同的失效模式。这些发现表明，当前的评估实践可能歪曲智能体在多元用户群体中的真实能力，并掩盖真实部署中的挑战。

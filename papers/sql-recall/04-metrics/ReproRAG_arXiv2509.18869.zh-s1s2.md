# On The Reproducibility Limitations of RAG Systems

## Abstract 摘要

检索增强生成（Retrieval-Augmented Generation, RAG）正越来越多地用于生成式人工智能驱动的科学工作流，以接入快速演化的科学知识库，但其可靠性经常因检索组件中的非确定性而受损。本文提出 ReproRAG，一个用于系统测量并量化基于向量的检索系统可复现性的综合基准框架。ReproRAG 考察整条流水线中的不确定性来源，包括不同的嵌入模型、精度、检索算法、硬件配置以及分布式执行环境。借助一组指标，如 Exact Match Rate、Jaccard Similarity 与 Kendall’s Tau，该框架有效刻画可复现性与性能之间的权衡。我们的大规模实证研究发现了关键现象；例如，不同嵌入模型对 RAG 可复现性有显著影响。开源的 ReproRAG 框架为研究者与工程师提供可用的工具，以验证部署、对可复现性做基准测试，并做出有依据的设计决策，从而促进更可信的科学人工智能。

## 1 Introduction 引言

检索增强生成（RAG）[12] 已成为构建知识密集型人工智能系统的基础架构，在科学研究中尤其如此 [20]。通过用来自大规模语料的检索证据约束大语言模型（LLM），RAG 系统减轻事实性幻觉 [8]，并提供领域相关、及时的信息。然而，当这些系统从原型走向科学工作流中的关键组件时，其可靠性与一致性变得至关重要，这也是更广泛的可信人工智能（Trustworthy AI）追求中的核心关切 [17]。

威胁这一可靠性的一个根本挑战是非确定性，这是并行与深度学习系统中已被充分记录的问题 [16]。即使输入完全相同，RAG 系统在多次运行中仍可能产生不同结果。这种不一致往往起源于基于向量的检索阶段。尽管其重要性显而易见，目前缺少标准化工具与方法来量化这种特定形式的非确定性。向量搜索的性能基准已有研究 [1]，但并不涉及可复现性，迫使研究者依赖轶事证据或临时测试。没有严格测量，就无法理解性能与一致性之间的权衡，无法验证生产部署，也无法有信心地建立在已有计算结果之上。

为填补这一测量空白，我们提出 ReproRAG，一个用于分析并测量 RAG 检索系统可复现性的综合测试框架。我们的贡献是：

- 我们设计并实现 ReproRAG，一个开源框架，用于系统基准测试 RAG 检索流水线的可复现性，并定义一组指标以量化不确定性的多个维度。
- 我们给出大规模实证研究，建立不确定性的层级，表明嵌入模型的选择与动态数据插入是结果变异最主要的来源。
- 我们提供详细的实证分析，挑战常见假设：核心近似最近邻（ANN）检索算法与分布式协议可以达到运行之间的完全可复现，而常见的软件级确定性开关对现代嵌入模型可能没有可观察的效果。
- 我们为实践者提供可操作的见解，包括对精度引起的 “embedding drift” 的量化，以及证据表明：对某些类别的模型，面向性能的设置可以在不损害可复现性的情况下带来加速。

## 2 Background and Related Work 背景与相关工作

### 2.1 Vector Search and Non-Determinism 向量搜索与非确定性

现代 RAG 系统依赖近似最近邻（Approximate Nearest Neighbor, ANN）搜索，以便在高维向量空间中高效找到相关文档。FAISS（Facebook AI Similarity Search）[9] 等库实现了多种 ANN 算法。这些方法常常以完美精度换取显著的速度提升，但这一权衡可能引入非确定性来源。

例如，Hierarchical Navigable Small World（HNSW）[13] 为搜索构建概率图，图构建过程中的选择可以成为随机性来源。类似地，Inverted File（IVF）索引先用 k-means 聚类划分向量空间，其随机初始化会导致不同的索引结构 [7]。另一常用技术 Locality-Sensitive Hashing（LSH）[5] 使用随机投影把相似项分组，投影的选择本质上是随机的。此外，在算法随机性之外，多核 CPU 或 GPU 上的并行执行会因浮点运算重排序而引入非确定性。

### 2.2 Related Work 相关工作

我们的工作位于三个关键领域的交叉处：RAG 在科学中的应用、计算可复现性这一更广泛的挑战，以及人工智能系统的基准测试实践。

**科学工作流中的 RAG。** 用大语言模型加速科学发现是一个快速增长的领域 [20]。RAG 框架尤其关键，它把这些模型锚定在专门、最新的科学文献上，使其成为假设生成与文献综述等任务的有力工具。SciTrust [6] 等框架评估的是 LLM 组件本身的可信性，并假定输入稳定、可复现。我们的工作与之互补，关注产生该输入的检索阶段的可靠性。

**计算科学中的可复现性危机。** 可复现性挑战是计算科学中已被充分记录的问题 [4]。作为回应，高性能计算社区推动提高研究可重复性，例如在主要会议上设立 Artifact Description and Evaluation 轨道 [3]。我们的框架把这些已确立的严格测量与验证原则，应用到大规模向量搜索系统所带来的具体而新颖的挑战上。

**人工智能与向量搜索系统的基准测试。** 标准化基准对人工智能系统的进步至关重要。MLPerf [15] 等努力已成为衡量机器学习训练与推理性能的行业标准。在向量搜索领域，ann-benchmarks [1] 等框架对不同 ANN 算法提供全面的性能比较。ReproRAG 把这一严格基准传统扩展到一个新的关键维度：可复现性。现有基准关注速度与精度，我们的工作则提供第一个用于量化这些系统一致性与确定性行为的综合框架。

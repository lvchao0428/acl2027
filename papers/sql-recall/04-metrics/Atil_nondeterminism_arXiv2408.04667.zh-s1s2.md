# Non-Determinism of “Deterministic” LLM Settings

## Abstract 摘要

大语言模型（large language model, LLM）的使用者常常注意到：在预期为确定性的设置下，相同输入仍会得到不同输出。据我们所知，这种现象有多普遍、以及对结果影响多大，尚未被系统研究。我们考察五款被配置为确定性的 LLM，将其用于八项常见任务，在 zero-shot 与 few-shot 两种设置下各运行 10 次。在自然出现的多次运行之间，准确率波动最高达 15%；最佳可能表现与最差可能表现之间的差距最高达 70%。事实上，没有一款 LLM 能在所有任务上稳定给出可重复的准确率，更谈不上输出字符串完全相同。与内部人员分享初步结果后可知，非确定性或许对借助输入缓冲区中混杂的数据来高效使用计算资源是必要的，因此这一问题短期内不会消失。为更好量化上述观察，我们提出面向确定性的指标：TARr@N，即 N 次运行上原始输出的总一致率（total agreement rate）；以及 TARa@N，即解析出的答案的总一致率。代码与数据公开于 https://github.com/breckbaldwin/llm-stability 。

## 1 Introduction 引言

大语言模型（LLM）在多种自然语言处理（NLP）及相关任务上表现良好，包括问答（Robinson & Wingate, 2023）、多种推理（Qiao et al., 2023）、代码生成（Jiang et al., 2024b）等。鉴于其通用性，以及在多种高风险社会功能中的广泛采用——例如医学信息获取（Shool et al., 2025）、法律（Niklaus et al., 2024）、财务规划（de Zarz `a i Cubero et al., 2024）或制造优化（Du et al., 2025）——人们越来越关注可靠性（例如分布外（Out-of-Distribution）行为（Liu et al., 2024; Du et al., 2022）），以及其他可信性方面（Shridhar et al., 2024; Chen & Mueller, 2024）。LLM 领域整体上一个值得肯定的特点是广泛使用基准数据集：你可以用客观指标知道自己“买到”的是什么。然而，若 LLM 的结果在多次运行之间不稳定，这些基准的价值何在？据我们所知，文献中尚未充分讨论的一个可靠性方面是：在假定为确定性的设置下，用户无法控制不同 LLM 与平台上输出的方差。我们表明，在一批高性能 LLM 上、于假定的确定性设置下，等价输入的多次运行存在令人警惕的差异。我们的发现说明，在人们期望稳健工程的领域里，不确定性实在太大。

除训练过程与数据外，temperature、top-k、top-p 与 repetition penalty 等超参数会显著影响模型表现（Wang et al., 2023）。

图 1：五个模型在八项任务上、zero-shot 与 few-shot 设置下，10 次运行中最大准确率与最小准确率的百分比差。

Top-k 与 top-p 依据概率缩小采样空间，temperature 则改变词表上的概率分布（Wang et al., 2020; 2023）。temperature 高时分布变平；接近 0 时，模型应当更加确定。许多 LLM 平台用户期望 temperature=0 时模型表现是确定的。另有许多用户可能已在该设置下观察到一定程度的非确定性，但对这一方差几乎没有量化。我们把这种尽管温度为零、输出仍然有方差的行为称为不稳定性（instability）。¹

尽管神经网络不同训练运行之间的不确定性已为人所知，衡量 LLM 在基准数据集上的表现时，报告单次结果已成为常规（Hendrycks et al., 2021; Suzgun et al., 2023; Wang et al., 2024; Gema et al., 2024; Rein et al., 2023），原因可能是成本与计算时间的限制。然而，若完全相同的训练运行之间输出存在显著方差，而不确定性度量（例如置信区间）又常常不被报告，基准的有效性就会下降。这里我们考察另一来源的不确定性：同一已训练模型、同一输入、temperature=0 时的表现方差。

本文分析多个模型族在两个常用基准任务上的不稳定性：Massive Multititask Language Understanding（MMLU）（Hendrycks et al., 2021）与 BIG-Bench Hard（BBH）（Suzgun et al., 2023）。图 1 表明模型并非确定的，且不稳定程度随模型、设置与任务而变化。因此，表现不稳定无疑会影响模型的排名。我们的具体贡献包括：

- 两个指标：TARr@N（N 次运行上原始数据的总一致率）与 TARa@N（N 次运行上解析答案的总一致率），用于刻画 LLM 不稳定性，分别捕捉答案准确率的变异与输出词跨度的变异。
- 在从两个常用基准 BBH 与 MMLU 中随机选取的 8 项任务上，量化 LLM 不稳定性。
- 比较不同设置，包括 zero-shot 与 few-shot（BBH 为 3，MMLU 为 5，与标准设置一致）。
- 分析不稳定性与准确率、输入长度、输出长度的相关。
- 提供运行数据与源代码。²

我们的系统研究按以下各节组织：引言、相关工作、控制 LLM 确定性、数据集、方法、实验、结果、讨论与结论。

¹ 本文中，稳定性/不稳定性与确定性/非确定性互换使用。

² 若论文被接收，将提供下载网址。

## 2 Related Work 相关工作

已有工作研究机器学习（machine learning, ML）模型在输入发生细微变化时的稳健性（Sehwag et al., 2019; Freiesleben & Grote, 2023; Hancox-Li, 2020; Rauber et al., 2017）。但我们关心的是：输入中的一切都保持不变时，响应如何变化。Biderman et al. (2024) 提出 LLM 的标准评测工具包并建议可复现性的最佳实践；然而不稳定性并未被讨论。提及不稳定性的工作包括 Song et al. (2024)，该文分析 temperature、采样策略、repetition penalty 与对齐算法对表现的影响。该工作发现 LLM 输出存在一定方差，评测基准应予以考虑，但他们使用的 temperature 为 1，从而引入了本研究试图最小化的变异。Ouyang et al. (2025) 对单一模型 ChatGPT 做了类似的不稳定性分析，在代码生成这一类任务上改变 temperature。最后，Holtzman et al. (2020) 提到文本生成的自由度可能导致相同输入得到不同输出，但他们没有讨论影响该行为的参数。据我们所知，尚无工作在输入与配置相同（zero-shot 与 few-shot）、并采用尽可能确定的超参数的条件下，系统研究 LLM 的不稳定性。

# RelBench v2: A Large-Scale Benchmark and Repository for Relational Data

## Abstract / 摘要

关系深度学习（relational deep learning, RDL）已经成为一种有力的范式：它跨多张互连的表来建模实体及其关系，从而直接在关系数据库上学习。随着这一范式走向更大的模型和关系基础模型，可扩展且现实的基准对于系统评估和推进至关重要。本文介绍 RELBENCH v2，这是面向 RDL 的 RELBENCH 基准的一次重大扩展。RELBENCH v2 增加了四个大规模关系数据集，覆盖学术出版物、企业资源规划、消费平台和临床记录，贡献超过 22 million 行、分布在 29 张表中，并把基准扩大到 11 个数据集。我们进一步引入自动补全任务（autocomplete tasks）。这是一类新的预测目标，要求模型在遵守时间约束的前提下，直接推断关系表内部缺失的属性值，从而超出以往经由 SQL 查询构造的传统预报任务（forecasting tasks）。此外，RELBENCH v2 还超出其自有数据集，整合了外部基准和评估框架：我们把 Temporal Graph Benchmark 的事件流转换成关系模式，以便做统一的关系–时间评估；与 ReDeLEx 接口，从而统一访问 70+ 个适合预训练的真实数据库；并纳入 4DBInfer 的数据集和任务，以拓宽多表评估的覆盖面。实验结果表明，在自动补全、预报和推荐任务上，RDL 模型一致优于单表基线，这突出了显式建模关系结构的重要性。

## 1 INTRODUCTION / 引言

关系数据库是企业、科学和医疗系统中结构化数据的主要存储抽象。它们把信息组织在多张通过主键–外键关系互连的表中，捕捉实体之间丰富的结构和时间依赖。预报任务，例如预测客户流失、估计销量、推荐产品，以及预判系统或患者结局，处于真实决策的中心，并推动了把机器学习用于关系数据的浓厚兴趣。

关系深度学习（RDL）（Robinson et al., 2024; Fey et al., 2024）已成为直接在关系数据库上学习的有力范式。它减少了传统机器学习流水线的人力和工程复杂度；那些流水线依靠手工特征工程和聚合，把关系模式展平成单张表。相反，RDL 把关系数据库当作异质图，并应用图神经网络（Robinson et al., 2024; Chen et al., 2025）以及其他关系表示学习架构（Dwivedi et al., 2026; 2025），直接建模实体及其关系。RDL 模型已在关系数据上的预报任务中表现出最先进的性能。

与此同时，机器学习的图景转向了基础模型：它们在大规模、多样化的数据上预训练，以学习可迁移的表示。这一范式改变了自然语言处理和计算机视觉，最近也延伸到表格数据，预训练模型在多种预测任务上表现强劲（Hollmann et al., 2023; 2025; Qu et al., 2025）。然而，这些方法关注的是单表数据，并不能捕捉关系数据库的多表结构。为弥补这一局限，最近的工作（Fey et al., 2025; Wang et al., 2025; Ranjan et al., 2026）为关系数据库开发基础模型，利用 RDL 架构来建模跨表的实体及其相互依赖。鉴于关系数据库无处不在且结构丰富，它们是基础模型自然的下一前沿，这也要求基准能够捕捉现实的关系结构和预测任务。

为支持关系数据库上预报的机器学习研究，Robinson et al. (2024) 提出了 RELBENCH，第一个面向 RDL 的基准。RELBENCH v1 提供一组真实关系数据库，以及要求预测未来结果的预报任务，例如实体流失、销量或推荐。这些任务使关系学习模型能够被标准化地评估，并表明 RDL 相对于传统方法是有效的。

本文介绍 RELBENCH v2，这是该基准的一次显著扩展，带来新的数据集、新的任务类型，以及关系预测的一种新范式。RELBENCH v2 增加四个新的大规模关系数据集，领域多样，使数据集总数达到 11 个。其中包括：rel-arxiv，一个学术出版物数据库，记录论文、作者、类别和引用关系；rel-salt，一个企业资源规划数据集，建模销售订单和业务流程；rel-ratebeer，一个消费平台数据集，包含用户交互、产品信息和评论；以及 rel-mimic，一个来自电子健康记录的临床数据集。这些数据集共同引入了新的关系结构、领域和预测挑战，合计包含超过 22 million 行，分布在 29 张表中。

除扩展数据集之外，RELBENCH v2 引入新的预测任务，并通过多种策略性整合，把多样的外部基准和诊断框架接进基准。最值得注意的是，RELBENCH v2 引入自动补全任务：目标是在给定时间戳预测关系表中已有列的取值，要求模型从关系和时间上下文中推断缺失值，同时防止信息泄漏。此外，在 RELBENCH v1 之后，后续工作扩大了关系基准的规模和多样性，我们把其中若干项整合进 RELBENCH v2。这包括来自 Temporal Graph Benchmark（TGB）（Rossi et al., 2020）的时间交互数据集，经由 ReDeLEx（Peleška & Šír, 2025b）在 70+ 个关系数据库上的广泛 RDL 评估，以及来自 4DBInfer（Wang et al., 2024）的、以图为中心的关系建模的 4D 设计空间。关于 RDL 和关系基础模型的进一步讨论见附录 A。

## 2 OVERVIEW AND DESIGN / 概述与设计

RELBENCH v1（Robinson et al., 2024）奠定了为关系数据库上的深度学习建立基准的框架。该基准由两个关键部分组成：一组多样的真实关系数据库，以及每个数据库所对应的一组现实预测任务。

- 关系数据库：由通过主键–外键关系连接的一组表组成。表中存放关于实体的多样信息，有些表包含时间列，表示行被创建的时间（例如交易日期）。每个数据库关联固定的 `VAL_TIMESTAMP` 和 `TEST_TIMESTAMP` 截止点：模型在直到 `VAL_TIMESTAMP` 的数据上训练，在 `VAL_TIMESTAMP` 与 `TEST_TIMESTAMP` 之间的行上验证，在 `TEST_TIMESTAMP` 之后的行上测试。推断时隐藏测试截止点之后的数据，以防止测试时泄漏（Kapoor & Narayanan, 2023），并使用 Fey et al. (2024) 的时间邻居采样策略。
- 预测任务按数据库定义，借助一张训练表（Fey et al., 2024）。每张训练表指定实体 ID、种子时间（seed time）和目标标签。种子时间决定预测在何时做出，并滤掉未来信息。重要的是，`VAL_TIMESTAMP` 与 `TEST_TIMESTAMP` 截止点在一个数据集内的所有任务之间共享，从而可以在同一关系数据库上定义的预测任务之间做多任务学习和预训练。

**Autocomplete tasks / 自动补全任务。** RELBENCH v2 引入自动补全任务，这是预测任务的一种新范式。这些任务允许对数据集中表内已有的列做预测，而不是像以往的预报任务那样，对经由 SQL 查询构造的目标标签做预测。不过，与预报任务一样，自动补全任务本质上仍然是时间性的。可以把自动补全任务想成：向数据库加入一行新记录，填上若干列，然后在不能访问未来数据的情况下预测其余列。对每个自动补全任务，我们定义一组固定的已观测列和一个待预测的目标列：模型在给定种子时间收到一行的已观测值，并且必须只用该时刻之前可用的关系和时间上下文来推断目标。

自动补全任务扩大了基准的用途，并拓宽了真实 RDL 应用的范围；要在自动补全任务上预测成功，模型必须深入理解数据的关系上下文。它们有许多真实应用。事实上，这些任务的灵感来自 SALT（Klein et al., 2024）的销售订单自动补全任务（见图 5）：SAP S/4HANA 销售订单用户界面根据其他数据字段的答案以及来自关系模式的上下文知识，推荐一个付款类别。

自动补全任务的一个关键考虑是防止信息泄漏，因为表中有些列可能高度相关。因此，设计自动补全任务时，需要丢掉那些与指定目标列相关的列。为防止信息泄漏，我们根据领域知识和对训练数据的检查，手工找出并移除与目标列高度相关的列。例如，在 rel-amazon 数据集的 review-rating 任务中，必须丢掉 `review_text` 列，否则它会与评论评分缠在一起、提供交织的信号。这样就避免了这类相互依赖的列去引导对目标列的预测，从而保持每个预测任务的真实性及其现实适用性。

**RDL implementation / RDL 实现。** RELBENCH v2 使用 Robinson et al. (2024) 所定义的同一 RDL 框架。重述如下：我们首先经由 PyTorch Frame（Hu et al., 2024），具体使用 ResNet 表格模型（Gorishniy et al., 2021），把原始的行级数据编码成初始节点嵌入。我们在给定种子时间、围绕每个实体节点做具有时间意识的子图采样（Fey et al., 2024），再把嵌入送入异质 GraphSAGE 模型（Hamilton et al., 2017; Fey & Lenssen, 2019），用基于求和的邻居聚合来迭代更新节点嵌入。最后，与任务相关的预测头把输出嵌入变成预测。

本文其余部分组织如下。第 3 节描述新的 RELBENCH 关系数据库。第 4 节和第 5 节介绍每个 RELBENCH 数据集上新的自动补全与预报预测任务，包括把我们的 RDL 实现与基线做基准比较的结果。最后，第 6 节描述通过整合外部数据集和多维 RDL 基准工具来扩展 RELBENCH 生态。

# ReFuGe: Feature Generation for Prediction Tasks on Relational Databases with LLM Agents

> 版权声明：本文档为同目录英文论文「摘要与正文前两节」的中文译文，仅供论文快速阅读与选题使用。译文不替代原文，不用于发表、再分发或商业用途。版权归原作者及出版方所有。原文件：`refuge-arxiv-2601.17735.pdf`。

## Abstract / 摘要

关系数据库（relational databases, RDBs）在许多真实的 Web 应用中起着关键作用，支撑着跨多张互连表的数据管理。除典型的面向检索的任务之外，RDB 上的预测任务近来受到关注。本文通过生成有信息量的关系特征来处理这一问题，这些特征用于提高预测性能。然而，生成这样的特征很困难：它要求在复杂模式上推理，并探索组合上很大的特征空间，而且没有显式监督。为应对这些挑战，我们提出 ReFuGe，一个智能体框架，使用专门化的大语言模型（large language model, LLM）智能体：（1）模式选择智能体找出与任务相关的表和列；（2）特征生成智能体从选定模式中产生多样的候选特征；（3）特征过滤智能体通过基于推理的过滤和基于验证的过滤，评估并保留有希望的特征。它在迭代反馈循环中运行，直到性能收敛。在 RDB 基准上的实验表明，ReFuGe 能在多种 RDB 预测任务上大幅提高性能。代码与数据集见 https://github.com/K-Kyungho/REFUGE。

## 1 Introduction & Related Works / 引言与相关工作

关系数据库广泛用于各类 Web 应用，例如在线零售平台、社交网络服务和论坛平台。多年来，RDB 研究在面向检索的任务上取得了显著进展，其目标是生成查询以抽取相关信息 [10, 11, 15]。最近，这一范围扩展到预测任务（例如分类），目的是利用 RDB 的关系结构来提高下游预测性能 [5–8, 17, 18]。

在 RDB 上做预测的一种实际而有效的途径，是生成能够捕捉分散在相关表中的预测信号的特征 [14]。例如，客户表可以用聚合后的购买统计、近期交易次数，或从其他表得到的关联账户属性来充实。有了这张包含生成特征的充实表，就可以直接使用标准的表格学习方法 [4, 12]。然而，在 RDB 中自动生成有效特征面临若干挑战。第一，它要求理解并从关系结构中抽取预测信号（C1）。第二，潜在特征的空间极大，因为表可以被变换或组合的方式很多（C2）。第三，特征生成缺少真值监督，因而无法直接做监督学习；这与检索任务（例如 text-to-SQL）不同，后者有真值查询可用（C3）。

为应对这些挑战，我们提出 ReFuGe（Relational Feature Generation），一个利用 LLM 推理能力的智能体框架。针对（C1），我们引入模式选择智能体，它找出 RDB 中那些为预测任务提供最相关关系信息的表和列。针对（C2），我们使用多个特征生成智能体，它们借助领域知识以及对关系上下文的理解，为预测表产生有意义的候选特征。得到的候选特征再经过基于推理的过滤和基于验证的过滤，被选择性地加入表中。最后，针对（C3），我们采用迭代式自我改进机制，使智能体能够在没有真值监督的情况下改进模式选择并生成特征。如图 1 所示，ReFuGe 逐步利用多张表中的信息生成新特征，使验证集上的 AUROC（area under the ROC curve，ROC 曲线下面积）随迭代持续提高。在多个 RDB 上的实验表明，ReFuGe 能够提高预测性能。

**图 1.** ReFuGe 跨迭代生成特征的一个例子。ReFuGe 迭代地生成关系特征，并把它们追加到目标表。图中可读的任务说明为：预测每位客户在未来 4 天内是否会点击多于一条广告。图中标注的 AUC 为 52.98、65.45 与 65.92，分别对应起始及 Iteration 1、Iteration 2。图中还出现“每位用户点击的不同广告数”“平均地理层级”等特征名，以及 UserInfo、VisitStream、SearchStream、Location 等表名和主键–外键关系。示意图中重复的框线字段不再逐条誊录。

**图 2.** ReFuGe 总览。通过（1）模式选择、（2）特征生成和（3）特征过滤，每一步由一个专门的 LLM 智能体完成。ReFuGe 迭代地生成关系特征，以充实目标表并提高 RDB 预测任务上的性能。每一轮都会生成反馈，并传给各智能体，以指导下一轮。图中还可读出：过滤分为 3.1 基于推理与 3.2 基于验证；验证分数上升则保留该特征，下降则丢弃；充实后的目标表送入表格模型（例如 LightGBM）。示意图内部的字段碎片【抽取不清】，此处不补全。

我们的主要贡献概括如下：

- **New Problem / 新问题。** 我们提出一个新问题：为 RDB 上的预测任务生成特征。
- **Agentic Framework / 智能体框架。** 我们提出 ReFuGe，一个用于在 RDB 中生成特征的、基于 LLM 的有效智能体框架。
- **Empirical Validation / 实证验证。** 我们表明，ReFuGe 在 7 个数据集、11 个任务上优于最先进的竞争方法。

## 2 Task Formulation / 任务形式化

给定一个关系数据库 \(R = \{T_1, T_2, \ldots, T_{|R|}\}\)，其中每张表 \(T_i \in R\) 包含一组实体（即行），并通过主键–外键关系与其他表相连。非正式地，我们假定每张表是一个异质特征矩阵 \(T_i \in F^{N_i \times d_i}\)，其中 \(N_i\) 与 \(d_i\) 分别表示实体数和特征数，\(F\) 表示可接受数据类型的空间（例如数值型、类别型）。

我们考虑定义在指定目标实体表 \(T_\star \in R\) 的目标实体上的预测任务（例如分类）。我们的目标是借助 \(T_\star\) 在整个关系数据库 \(R\) 中的关系上下文，为 \(T_\star\) 生成额外特征。生成的特征再与 \(T_\star\) 的原始属性拼接，用于训练一个表格模型（例如 LightGBM [12]）。

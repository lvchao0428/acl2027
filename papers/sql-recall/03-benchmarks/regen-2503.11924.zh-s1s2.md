# REGEN: A Dataset and Benchmarks with Natural Language Critiques and Narratives

## Abstract 摘要

本文介绍一个新数据集 REGEN（Reviews Enhanced with GEnerative Narratives），用于评测推荐大语言模型（Large Language Models, LLMs）的对话能力，以应对现有数据集主要聚焦序列物品预测的局限。REGEN 通过补全（inpainting）两类关键自然语言特征来扩展 Amazon Product Reviews 数据集：（1）用户批评（critiques），即导致后续物品被选中的用户“引导”查询；（2）叙述（narratives），即与每个被推荐物品相关联、并考虑先前上下文的丰富文本输出。叙述包括商品背书、购买解释以及用户偏好摘要。

此外，我们为对话式推荐任务建立端到端建模基准：模型在用户历史（物品与批评）的条件下，被训练为同时生成推荐与对应叙述。针对这一联合任务，我们提出建模框架 LUMEN（LLM-based Unified Multi-task Model with Critiques, Recommendations, and Narratives），它以 LLM 为骨干，用于批评、检索与生成。我们还用标准的自动评分技术评估数据集质量，并通过训练传统推荐模型与基于 LLM 的推荐模型来做基准评测。结果表明，纳入批评能够使推荐器学习语言理解并将其与推荐信号相结合，从而提升推荐质量。此外，在我们的数据集上训练的 LLM 能够有效地同时生成推荐与上下文叙述，达到与最先进推荐器和语言模型相当的性能。

## 1 Introduction 引言

把大语言模型（LLMs）用于对话式推荐器 [9, 27, 35, 50, 53] 近来受到一些关注。除了提供个性化推荐，对话式推荐器还与用户进行自然对话，例如解释推荐、根据用户的自然语言反馈改进推荐。LLM 在满足这类推荐器所需的语言能力方面显示出前景。

这具有挑战性，因为现有用于训练对话式推荐系统的数据集缺少丰富的上下文叙述与显式的用户反馈。这样的数据集对于在被推荐物品的上下文中建模自然语言交互至关重要，从而使生成的文本与推荐及用户偏好一致且相关。尽管若干近期工作探索把推荐器内部状态与 LLM 相结合的建模方法 [16, 36, 50, 53]，它们受限于现有数据集（例如 [5, 9, 25, 27, 34, 47]），这些数据集集中于用户物品序列、短对话片段、结构化输出，或缺少丰富多样对话要素的小摘要。

从用户处收集这样的数据集具有挑战，通常需要大量真实用户与对话式推荐器交互。因此，我们延续 [6, 23, 34] 的趋势，探索如下假设：LLM 能够（1）从现有用户行为轨迹数据集中推断用户偏好与目标；（2）生成与真实行为一致的、有说服力且合理的用户叙述与回复。除了便利之外，这一方法的一个优点是我们可以增强现有流行的序列推荐数据集。

我们提出 REGEN（Reviews Enhanced with GEnerative Narratives），一个通过纳入与对话式推荐相关的自然语言输出来增强 Amazon Reviews 数据集 [34] 的数据集（图 1）。REGEN 增加多样的叙述，例如购买原因、解释、商品背书、用户摘要与简洁的用户画像，并且对每个用户个性化。它还增加合理的批评，即用户为引导推荐器而对推荐作出回应时发出的自然语言反馈。为增强数据集，我们使用 Gemini 1.5 Flash [44]，以少样本提示来补全叙述与批评。LLM 利用原始 Amazon Reviews 数据集中用户的评分历史、商品评论文本与物品描述来生成这些特征。作为可行性的初步度量，我们用自动评分 LLM [10] 自动检查质量。自动评分者在多个属性上评估生成输出，重点是基于用户历史交互的依据性（grounding）与事实性。

除了数据集，还需要一个把用户行为与推荐整合在一起的单一训练任务，以评估模型在这些方面的一致性与处理能力。尽管许多先前研究（例如 [9, 36]）提出以各自独立的目标训练模型，例如做推荐、评分预测或评论生成，我们认为把这些方面结合起来的任务，是评估对话式推荐中连贯性的关键一步。为辅助模型开发，我们提出单轮对话任务，作为走向完全对话式推荐器的一步。在该任务中，模型输入是物品的用户历史，并在部分物品之间结合用户批评。输出是下一个要推荐的物品，以及与所推荐物品和用户偏好一致的丰富自然语言叙述。该任务要求模型把个性化序列推荐、批评与自然语言生成有效地结合为完全对话式推荐器的单一、连贯轮次。

最后，为评估 REGEN 数据集与任务二者的效用，我们给出参考模型与强基线。这里我们提出 LUMEN（LLM-based Unified Multi-task Model with Critiques, Recommendations, and Narratives），一个使用 LLM 骨干的单一模型，通过整合协同过滤信号、内容信号与自然语言批评输入，被训练来生成推荐与叙述。LUMEN 利用用户–物品交互数据、丰富的物品内容表示以及用户反馈，生成信息充分且与用户偏好对齐的输出。我们的实验建立了基准，展示该架构在产生类人对话式推荐方面的有效性。

总之，关键贡献是：

- REGEN，一个开源数据集，带有与用户消费历史一致且个性化的批评与丰富自然语言叙述。我们从事实性、依据性以及准确反映用户上下文等方面评估它。
- 一个通向完全对话式推荐器的对应任务，可作为未来研究的基础。
- 参考模型表明，把生成式推荐与语言任务相结合的 LLM 架构，能够达到与最先进推荐器和语言模型相当的性能。
- 验证了模型学习并生成上下文丰富的叙述、以及利用用户批评动态引导推荐的能力。我们进一步展示连贯对话轨迹的生成。

## 2 Related Work 相关工作

REGEN 受到支持推荐系统开发与评估的现有数据集和建模任务启发。

数据集：https://www.kaggle.com/datasets/googleai/regen-reviews-enhanced-with-generative-narratives

### 2.1 Datasets 数据集

#### 2.1.1 Conversational 对话式

许多对话数据集是基于对话的，表示用户与智能体之间的交谈。例如，DuRecDial [29, 30] 是一个众包的、带有预定义目标的多领域对话数据集。E-ConvRec [19] 提供一个基于用户与客服之间真实售前对话的大规模对话推荐数据集。ReDial [24] 是电影推荐对话的标注数据集。TG-ReDial [52] 通过纳入话题信息来引导对话与推荐，从而扩展 ReDial；E-Redial [12] 则用外部知识扩展它以改进可解释性。这些数据集聚焦于构建或收集对话，但通常缺少对话与用户底层偏好或历史行为之间的耦合。LLM-Redial [27] 以用户为中心，通过模板、植根于真实用户画像来创建对话。REGEN 与 LLM-Redial 相似之处在于关注维持用户画像与叙述之间的一致性，但有若干不同。第一，REGEN 保留序列物品历史以维持时间一致性，从而能够以过去的用户行为为条件生成用户反馈与叙述。第二，REGEN 关注的不是短对话轮次，而是一个知识丰富的对话式推荐器可能产生的个性化、丰富叙述。我们相信，一个以叙述为中心的数据集有助于在被推荐物品与用户偏好的上下文中检验推荐器的语言理解。

#### 2.1.2 Narratives 叙述

Ni 等人的 “Justifying Recommendations” 数据集 [34] 与 Chen 等人的 “Unlocking the Why of Buying” [5] 聚焦于从评论生成解释。Hou 等人的 “Amazon-C4” 数据集 [15] 提出一个新的评论数据集，构建复杂查询并将其与物品关联，以在推荐任务上评估模型。REGEN 用适合若干推荐任务的开放式叙述扩展他们的工作，以整个用户历史为条件，并覆盖购买解释之外的用例。REGEN 针对反映 LLM 迅速演进能力的自然语言输出，包括更长、更细致、半结构化与非结构化的回复。

#### 2.1.3 Critiquing 批评

经典推荐系统中的批评在 Chen and Pu [4]、Gao 等人 [8]、Jannach 等人 [18] 中有综述。早期批评系统使用户能够对推荐物品提供反馈，通常在特征层面，通过（例如）建议预先设计的微调 [2]，或由语言驱动的对话系统 [11, 41, 46]。近期工作 [31, 32, 48] 探索联合学习用户、物品与关键短语的潜在表示，其中关键短语作为可以通过潜在空间中的操作影响推荐的批评。另一些工作探索对属性的解释 [1, 33] 以支持批评。这些工作为把自然语言批评作为 REGEN 所提供的用户反馈载体奠定了基础。

### 2.2 Recommendation Tasks 推荐任务

#### 2.2.1 Sequential Item Recommendations 序列物品推荐

为把 LLM 与推荐系统结合起来做序列推荐，已有大量持续研究 [3, 7, 13, 14, 21, 26, 28, 36–38, 40, 42, 49, 51, 54]。这些模型探索表示物品与用户交互的不同方法（例如 ID 嵌入、文本嵌入），其中一些寻求通过纳入物品和/或语义上下文来提升质量。物品推荐是 REGEN 支持的一项重要的首要任务。由于它基于流行的基准数据集 Amazon Reviews，我们相信 REGEN 自然适合把现有基于 LLM 的序列推荐器扩展到同时生成语言。

#### 2.2.2 Item Recommendation and Text Generation 物品推荐与文本生成

有不少推荐模型同时输出物品推荐与自然语言。P5 [9] 把全部用户–物品信号连同相关上下文表示为自然语言序列，输入编码器/解码器模型。它提出若干用于物品预测与文本生成的任务族。User-LLM [36] 把用户历史编码为用户嵌入，并通过交叉注意力将其纳入 LLM。User-LLM 支持三项任务：下一物品推荐、类型预测与评论生成。尽管这些项目提出同时涉及推荐与文本生成的任务，它们是分开的任务。与此相对，REGEN 提议把这两项任务连同用户反馈一起整合为单一连贯任务，同时生成丰富多样的叙述集合。

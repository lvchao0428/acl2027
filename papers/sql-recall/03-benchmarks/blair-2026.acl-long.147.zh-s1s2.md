# Bridging Language and Items for Retrieval and Recommendation: Benchmarking LLMs as Semantic Encoders

## Abstract 摘要

特征工程长期以来一直是推荐系统的核心，但有效利用文本形式的物品特征仍然具有挑战。大语言模型（large language models, LLMs）的最新进展使其可以被用作推荐中的语义编码器，但它们在这一设定下的角色与行为仍未被充分理解。先前研究在选择 LLM 时往往依赖通用嵌入基准（例如 MTEB），从而忽略了推荐任务的独特特点。为填补这一差距，我们提出 BLAIR，一个用于在推荐场景中评估 LLM 作为语义编码器的综合基准。我们的贡献包括：（1）一个新的大规模 Amazon Reviews 2023 数据集，包含超过 5.7 亿条评论与 4,800 万件物品；（2）一个统一基准，覆盖序列推荐、协同过滤与商品搜索；（3）一个新的复杂查询商品搜索任务，同时包含半合成与真实世界评测数据集。对 11 个领先 LLM 的实验表明，它们在 BLAIR 上的排名与 MTEB 几乎不相关，凸显了推荐中语义编码的独特挑战。

## 1 Introduction 引言

特征工程长期以来一直是现代推荐系统的核心（Rendle, 2010; Chen et al., 2012; Cheng et al., 2016）。然而，有效利用文本信息（例如物品描述）一直是一项挑战。文本特征语义丰富，但往往嘈杂、非结构化，并且难以直接整合进推荐模型。早期方法依赖关键词标注（Mooney and Roy, 2000; Wang and Blei, 2011; Tang et al., 2012），这些方法大体上是启发式的，并丢弃了大量语义信息。此外，文本特征通常用浅层统计技术建模，缺少自然语言中固有的更广泛常识。

随着大语言模型（LLMs）的迅速进展（Hoffmann et al., 2022; Rae et al., 2021; Chowdhery et al., 2023; Touvron et al., 2023; Zhao et al., 2023），研究者开始把它们用作推荐的语义编码器。在大规模语料上预训练的 LLM 捕获了广泛的世界知识，并在理解与表示自然语言方面表现出强能力。因此，越来越多的研究探索把 LLM 编码的文本表示作为输入来训练推荐模型，这一方向被称为基于模态的推荐（modality-based recommendation）（Hou et al., 2022; Yuan et al., 2023）。该范式在多种任务上显示出有前景的结果，包括序列推荐（Hou et al., 2022; Yuan et al., 2023）、协同过滤（Ren et al., 2024; Sheng et al., 2024）以及商品搜索（Li et al., 2021; Reddy et al., 2022）。

尽管有这些进展，LLM 作为推荐中语义编码器的角色仍未被充分理解。现有研究通常采用流行或新近发布的 LLM，或依赖 MTEB（Muennighoff et al., 2023; Enevoldsen et al., 2025）等通用句子嵌入基准来选择模型。然而，推荐的要求与通用文本嵌入任务有实质性差异。（1）在推荐中，编码表示通常被用作输入特征，以训练下游模型，例如用于序列推荐的 Transformer 解码器；而在文本嵌入任务中，表示更常被直接用于相似度搜索或简单分类器。（2）在推荐中，文本输入往往短且嘈杂（例如物品标题），要求语义编码器基于世界知识提供强的消歧能力；而文本嵌入基准通常评估格式完整的句子或段落。

为填补这一差距，我们提出 BLAIR，即 Bridging Language and Items for Retrieval and Recommendation，一个旨在于推荐场景中评估 LLM 作为语义编码器的综合基准（图 1）。我们的贡献如下：

- **一个新的大规模电商数据集：Amazon Reviews 2023。** 先前的 Amazon Reviews 数据集（McAuley et al., 2015; He and McAuley, 2016; Ni et al., 2019）被广泛用于基准评测，但发布于数年前（最近一次发布在 2018 年），且包含嘈杂的元数据。我们收集了一个带有清洗元数据的新数据集，包含超过 5.7 亿条评论与 4,800 万件物品，截止日期为 2023 年 9 月。
- **一个综合基准：BLAIR。** 我们评估三种有代表性的推荐场景：序列推荐、协同过滤与商品搜索。对每一种，我们实现强基线，并在 MTEB 上表现最好的 11 个 LLM 上开展广泛实验。
- **一个新的子任务：复杂查询商品搜索。** 现有商品搜索数据集通常涉及短查询。为对齐那些需要理解长而复杂、且含歧义的查询的新兴应用，我们引入一个新的子任务：复杂查询商品搜索。我们构建两个数据集：一个由真实用户评论派生的半合成数据集，以及另一个由真实世界论坛帖子整理而成的数据集。

我们的结果产生若干值得注意的洞见：（1）LLM 在 BLAIR 上的排名与它们在 MTEB 上的排名并非正相关，说明推荐相对于通用嵌入基准提出了不同的挑战。（2）即使下游模型参数量相同，性能仍随语义编码器规模而提升，不过随着任务复杂度增加，这一效应会减弱。（3）我们观察到，复杂查询商品搜索任务上半合成数据集与真实世界数据集的结果之间存在强相关，这意味着半合成数据可以成为有成本效益的评测代理。

## 2 Related Work 相关工作

**推荐中的语义编码器（Semantic Encoders in Recommendation）。** 研究者长期寻求更好地利用标题与描述等语义丰富的文本特征。基于内容的推荐的早期工作（Mooney and Roy, 2000; Gopalan et al., 2014）抽取关键词，并学习用户与物品之间的协同关系（Rendle, 2010; Wang and Blei, 2011; Chen et al., 2012; Wang et al., 2015）。随着自然语言处理（NLP）的进展，后续研究开始用预训练模型直接编码文本特征，以更好地捕获语言语义（Chen et al., 2017; Hou et al., 2022; Yuan et al., 2023）。然而，这类模型常常受困于预训练数据与推荐场景之间的领域差距（Hou et al., 2023）。近来，具备更优泛化能力的 LLM 的出现，促使研究者探索把 LLM 用作推荐中的语义编码器（Wei et al., 2024; Ren et al., 2024; Ren and Huang, 2024; Sheng et al., 2024）。尽管如此，关于 LLM 的选择如何影响下游性能，问题仍然存在。

**文本嵌入的基准评测（Benchmarking Text Embeddings）。** 为了跨领域与任务全面评估文本嵌入模型，研究者开发了聚合多个公开数据集的基准。早期例子是 BEIR（Thakur et al., 2021），它在信息检索任务上评估文本嵌入模型。MTEB（Muennighoff et al., 2023）与 MMTEB（Enevoldsen et al., 2025）进一步把评测范围从检索扩展到分类与聚类等更广泛的嵌入应用。最近，BRIGHT（Su et al., 2025）聚焦于需要推理才能识别相关文档的检索任务。本文旨在把文本嵌入模型作为推荐场景中的语义编码器来做基准评测。这并非仅仅是领域特定的改编，而是反映了：作为语义编码器，LLM 需要不同的能力。

**面向推荐的 LLM 基准评测（Benchmarking LLMs for Recommendation）。** 现有面向推荐来评测 LLM 的工作可分为三类：（1）把它们作为购物智能体，评测其真实世界网页交互能力（Yao et al., 2022; Wang et al., 2025）；（2）评测其与购物相关的知识以及对用户意图的理解（Jin et al., 2024）；（3）把 LLM 本身作为推荐模型来评测（Liu et al., 2023, 2024; Jiang et al., 2025; Liu et al., 2025）。与此相对，据我们所知，我们是第一个在推荐场景中对用于编码文本特征的 LLM 做基准评测的工作。

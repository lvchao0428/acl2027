## Abstract 摘要

Explore Further @ Bing 是一项网页到网页的推荐产品，通过呈现与搜索结果 URL 相关联、且能吸引用户的网页推荐，来增强 Bing 上的搜索体验。本文介绍我们如何利用大语言模型（Large Language Models, LLMs）来增强这一网页规模的推荐系统。我们描述由 LLM 驱动的推荐质量指标 RecoDCG 的开发与验证。我们讨论利用 LLM 使排序阶段具备质量感知能力的核心技术。进一步，我们详述 Q' recall：这是一条召回通路，借助 LLM 生成互补且吸引人的推荐候选，从而增强系统的候选生成阶段。我们还说明如何针对多目标优化系统，在推荐质量与点击指标之间取得平衡。我们将该工作部署到生产环境，使推荐质量获得显著提升。我们分享离线与在线实验的结果，以及为使这些方法有效扩展到网页规模需求所采取的步骤与得到的认识。

## 1 Introduction 引言

Explore Further（见图 1）位于 Bing 搜索结果页，提供与查询无关、也与用户无关的网页推荐。我们的推荐系统是业界规模最大的系统之一，索引总量超过 200 billion 个网页。构建大规模推荐系统时，一个仍然突出的挑战是获取可靠的质量与相关性标签以用于训练。尽管人工评测通常能提供高质量的相关性标签，但人工标注成本高、耗时长，而且常常不一致。仅靠人工标签，很难把一个规模巨大且持续变化的推荐系统扩展起来。这一点对系统的训练和评估都成立。

业界许多产品把用户点击等隐式反馈当作优化推荐系统的有价值信号。然而，过度关注点击指标有时会导致系统偏向标题党（clickbait）和低质量推荐 [6]。由于文档质量在整个 Web 上差异很大，这一问题对网页推荐系统尤为关键。历史上，我们的系统主要依据用户交互与行为信号进行训练。随着时间推移，我们在用户针对该功能提交的不满反馈中反复看到同一主题，集中指向对标题党和低质量网页推荐的担忧。

就我们的索引规模而言，不可能对进入索引的网页逐一筛选，因此我们面临把垃圾信息、标题党甚至不适当网页暴露给用户的风险。LLM 已展现出一种涌现能力，能够理解用户意图，并捕捉用户意图与文档内容之间的语义关系。近期研究表明，LLM 能够准确理解网页搜索者的偏好，并生成高质量的相关性标签 [11]。受此推动，我们开发了 RecoDCG，一种由 LLM 驱动的离线推荐质量指标，便于快速评估新技术。我们进一步使用这些质量标签，使排序阶段具备质量感知能力。

我们首先简要概述生产环境中的网页到网页推荐系统，并说明如何使用 LLM 开发可靠的质量评估指标 RecoDCG，给出我们所遵循流程的一份操作说明。我们在 Section 4 深入讨论质量感知排序系统，并在 Section 5 阐述如何应用 LLM 进行互补候选生成。

## 2 System Overview 系统概览

该网页推荐功能的关键产品目标，是向用户提供有趣、互补且相关的文档，这些文档与出现在搜索结果前 3 个位置的 URL 相关联。最好的网页推荐，要么满足用户的下一次查询意图，要么提供另一种视角，要么引入与 URL1 相关的探索性主题。我们将主（触发）网页称为 URL1，将推荐候选称为 URL2。在图 1 中，cheatsheet.md 是 URL1，Explore Further 下方被推荐的网页视为 URL2。

这些推荐只依赖于 URL1，与用户以及用户的搜索查询都无关。在召回阶段（候选选择），我们从 Bing 索引中的 several hundred billion 个网页文档里生成相关候选。系统有多条召回通路：co-click、协同过滤（collaborative filtering）、双塔嵌入模型，以及我们将在 Section 5 详述的、新的由 LLM 驱动的召回通路。如图 2 所示，候选网页被聚合后送入两层排序阶段。

### 2.1 Candidate Generation Stage Overview 候选生成阶段概览

生产系统有多个候选生成器，称为召回通路（recall paths）。每条召回通路经过调参，从 Bing 的 200 billion 网页索引中产生特定数量的候选。这些候选在进入排序阶段之前被聚合并去重。我们将两个网页之间的 co-click（co-occurrence click）定义为：多个 Bing 用户浏览会话中都包含对二者的点击，表明存在一定程度的相关性。基于共点击信息构建图之后，我们用协同过滤（CF）在数十亿网页的规模上学习网页嵌入。我们训练一个基于 6 层 XLM-Roberta [4] 的双塔 Transformer 模型，以点击日志为标签学习网页嵌入；每个塔处理 URL 及其关联的文本特征。推理时，对于触发 URL1，CF 与双塔模型这两条召回通路都基于嵌入的余弦相似度，用近似最近邻（Approximate Nearest Neighbor, ANN）搜索来检索相似网页 [5]。本文引入一条新的、由 LLM 驱动的 Q' 召回通路，为 hundreds of millions 个 URL1 生成多样且互补的候选。我们在 Section 5 详细讨论 Q' recall。

### 2.2 Ranking Stage Overview 排序阶段概览

系统的排序阶段按顺序包括：

1. Stage 1：LightGBM 排序器，使用较小的一组廉价特征，主要是不同时间窗口上的 URL1–URL2 点击计数与曝光计数特征。
2. Stage 2.a：MT RecoLM，一个多任务交叉编码器（cross-encoder）模型，有两个头，分别针对成对点击预测与推荐质量任务进行训练。
3. Stage 2.b：LightGBM 排序器，使用更大的一组更昂贵的特征，其中包括交叉编码器模型各头的分数。该排序器以成对点击预测目标（LTR）进行优化。
4. Stage 2.c：Stage 2 的 LightGBM 排序分数与推荐质量头分数的线性组合。

我们在 Section 4 详细讨论质量感知排序。

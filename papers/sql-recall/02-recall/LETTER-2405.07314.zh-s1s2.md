# Learnable Item Tokenization for Generative Recommendation

## Abstract 摘要

利用强大的大语言模型（Large Language Models, LLMs）做生成式推荐已经吸引了大量关注。尽管如此，一个关键挑战是通过有效的物品切分（item tokenization），把推荐数据变换到 LLM 的语言空间。当前方法，例如基于 ID、文本和码本的标识符，在编码语义信息、纳入协同信号或处理码分配偏差上存在不足。为解决这些局限，我们提出 LETTER（a LEarnable Tokenizer for generaTivE Recommendation），它整合层次语义、协同信号和码分配多样性，以满足标识符的基本要求。LETTER 纳入残差量化 VAE（Residual Quantized VAE）做语义正则，用对比对齐损失做协同正则，并用多样性损失来缓解码分配偏差。我们在两个模型上实例化 LETTER，并提出一种排序引导的生成损失，从理论上增强它们的排序能力。在三个数据集上的实验验证了 LETTER 的优越性，推进了基于 LLM 的生成式推荐领域的最先进水平。

## 1 Introduction 引言

利用大语言模型（LLMs）做生成式推荐已经成为一条突出的途径，吸引了大量研究兴趣 [14, 32]。借助 LLM 的强大能力（例如丰富的世界知识、推理和泛化），许多工作正在研究把 LLM 用于生成式推荐，展示了构建基础 LLM、从而从自然语言处理走向信息检索和推荐领域的潜力 [6, 9]。如图 1 所示，给定用户历史上交互过的物品，生成式推荐旨在利用 LLM 生成目标物品作为推荐。通过 LLM 编码和生成物品的一个关键问题是物品切分（item tokenization）：它用一个标识符（即一串 token 序列）索引每个物品，从而弥合推荐数据与 LLM 语言空间之间的差距。因此，研究基于 LLM 的生成式推荐中的物品切分是必要的。

现有物品切分方法主要探索了三类标识符来索引物品：

- ID 标识符为每个物品分配一个唯一的数字字符串（例如 “28,128”），以保证标识符的唯一性 [9, 14]。然而，数字 ID 在编码语义信息上效率低，难以泛化到冷启动物品 [39]。
- 文本标识符直接利用物品语义信息，例如标题、属性或/和描述，作为物品标识符 [1, 14]。尽管如此，这类文本标识符存在以下问题：1）语义信息在标识符的 token 序列中并不是从粗到细层次分布的。如果目标物品的前几个 token 与用户偏好并不紧密对齐（例如电影标题中的 “With” 和 “Be”），这会导致生成概率低；2）文本标识符缺少来自用户行为的协同信号 [1]。标识符的 token 序列完全由语义信息决定。因此，语义相似但协同信号不同的物品会表现出相似的 token 序列，从协同过滤（Collaborative Filtering, CF）的角度看削弱了物品的可区分性（见 Section 2 和图 2）。
- 基于码本的方法采用自编码器，把物品语义编码为层次码序列作为标识符 [32, 50]。然而，与文本标识符类似，基于码本的标识符在码序列中仍然缺少协同信号（见 Section 2）。此外，如图 3 所示，码到物品的分配天然不平衡，造成物品生成偏差：带有高频码的物品更容易被生成。

鉴于这些考虑，一个理想的标识符应当满足以下标准：

- 把层次语义整合进标识符：token 序列先编码宽泛、粗粒度的语义，再逐步过渡到更精细的细粒度细节。这与生成式推荐的自回归生成特性一致。
- 把协同信号纳入 token 分配：确保在用户行为中具有相似协同信号的物品，拥有相似的 token 序列作为标识符。
- 提高 token 分配的多样性，以缓解物品生成偏差，从而保证物品生成的公平性。

为此，我们提出名为 LETTER 的、用于生成式推荐的可学习分词器（a LEarnable Tokenizer for generaTivE Recommendation）。LETTER 纳入三种正则，以增强基于码本的标识符。具体而言，语义正则首先整合残差量化 VAE（Residual Quantized VAE, RQ-VAE）[16]，把物品语义信息翻译为层次标识符 [32]。在此基础上，协同正则利用对比对齐损失，把 RQ-VAE 中的语义量化嵌入与来自训练良好的 CF 模型（例如 LightGCN [11]）的 CF 嵌入对齐。此外，LETTER 引入多样性损失，以增强码嵌入的多样性，从而缓解码分配偏差和物品生成偏差。我们在两个有代表性的生成式推荐模型上实例化 LETTER，并提出一种排序引导的生成损失，从理论上提升这些生成模型的排序能力。在三个数据集上的大量实验和深入考察已经验证：通过同时考虑标识符中的层次语义、协同信号和码分配多样性，LETTER 能够实现更优的物品切分。为便于复现，我们在 https://github.com/HonghuiBao2000/LETTER 发布代码和数据。

总之，本工作的贡献如下。

- 我们全面分析理想标识符的必要特征。据此，我们提出一个名为 LETTER 的新可学习分词器，旨在自适应地学习同时涵盖层次语义、协同信号和码分配多样性的标识符。
- 我们在两个生成式推荐模型上实例化 LETTER，并利用排序引导的生成损失，从理论上增强生成式推荐模型的排序能力。
- 我们在三个数据集上进行大量实验，并结合多样设置下的深入考察，验证 LETTER 在生成式推荐上优于现有的物品切分方法。

## 2 Item Tokenization 物品切分

生成式推荐旨在给定用户历史交互后生成下一项物品 [17]。基于 LLM 的生成式推荐中，一个关键的基础步骤是物品切分，它为每个物品分配一个标识符。每个标识符是一串 token 序列，用以协助 LLM 做物品编码和生成。通过物品切分，基于 LLM 的生成式推荐模型可以：1）把用户的历史交互变换为一串标识符以便物品编码；2）自回归地生成一个物品标识符用于下一项推荐（见图 1(b)）。

现有物品 token 方法探索了 ID 标识符 [4, 9, 14, 43]、文本标识符 [1, 47, 49] 和基于码本的标识符 [32, 50]。然而，ID 标识符在语义编码上能力不足 [39]。此外，我们更详细地给出文本标识符和基于码本的标识符中的关键问题。

- 非层次语义。如 Section 1 所述，文本标识符中的语义信息并不是从粗到细层次分布的。
- 缺少协同信号。先前的文本标识符和基于码本的标识符在 token 序列的构成中不考虑协同信号。它们通常在 LLM 训练阶段把协同信号注入标识符的 token 嵌入（例如 TIGER [32] 和 LC-Rec [50]）。然而，如图 2 所示，语义相似的两个物品总是共享相似的 token 序列和嵌入，因而难以与协同信号对齐。通过训练把协同信号注入这两个物品的标识符嵌入，会造成冲突。
- 码分配偏差。基于码本的方法还额外遭受不平衡的码分配，导致物品生成偏差。我们在 Instruments 数据集上用 TIGER [32] 做实证考察。具体而言，我们根据物品标识符码在训练数据中的分配流行度把它们分成五组，并得到 TIGER 的生成频率。从图 3 可以观察到，流行的物品标识符更可能被生成，从而放大生成偏差。

鉴于这些，我们认为追求理想标识符有三个必要目标：1）把层次语义整合进 token 序列；2）把协同信号整合进 token 序列；3）码分配的高多样性。

## 摘要

推荐模型擅长用大量行为数据做领域内的物品推荐，像轻量的领域专家，但解释和对话这类开放任务做不好。大语言模型则强在指令理解、常识推理和与人交互，却不掌握领域物品目录和行为模式，尤其是偏离一般世界知识的场景，例如在线电商。为每个领域微调 LLM 既不经济也不高效。InteRecAgent 把两边接起来：LLM 当大脑，推荐模型当工具。

摘要先给出把 LLM 变成该智能体所需的最小工具集，再给出执行工作流，关键部件是记忆组件、用动态示例增强的任务规划，以及反思。这样，传统推荐系统，包括基于 ID 的矩阵分解，可以通过 LLM 获得自然语言交互界面。若干公开数据集上的实验称，作为对话推荐系统，InteRecAgent 表现令人满意，并超过通用 LLM。摘要没有具体指标。

## 1 Introduction

第一节的主张是：对话式发现商品需要的不是再做一个更深的排序模型，而是把领域推荐模型接到 LLM 上。推荐系统从协同过滤走到融合深度学习的混合方法，但用户越来越用对话来探索商品。GPT-3、PaLM 以及 ChatGPT、Claude 这类智能体表明，LLM 能理解上下文、生成接近人的文本并做复杂推理，因此有可能让推荐超出传统打分。限制也有三条。预训练语料覆盖很广，却抓不住细粒度、尤其是训练数据极大的领域行为；领域数据若是私有、网上不公开，LLM 更难理解；预训练截止日期之后的新物品它不知道，用最新数据再微调又太贵。领域内模型正好补这三处。已有接法是让 LLM 当大脑、领域模型当工具，例子包括 AutoGPT、HuggingGPT 和 Visual ChatGPT。

InteRecAgent（Interactive Recommender Agent）把这套接法收成推荐专用框架。工具分成查询、检索、排序三组，对应日常问询的不同需求。候选物品通常很多，把物品名写进工具的输入输出、再塞进提示当观察，并不现实，因此用 shared candidate bus 存放中间状态，并让工具之间通信。为了长对话甚至终身对话，再用 long-term and short-term user profile 跟踪偏好和历史，作为排序工具的输入。这两部分构成框架里的记忆机制。规划上不用逐步调用，而用 plan-first execution：一次生成全部工具调用步骤并严格照做，从而降低 LLM 的推理成本，也便于和动态示例结合。对话中先解析意图，再检索与当前意图最相似的少数示例，帮助 LLM 写出正确计划。另外有反思：另一个 LLM 当批评者，检查结果质量和执行错误；不满意就回到初始状态，重做「先计划、再执行工具」。

用 GPT-4 当大脑时实验效果很好，于是作者问更小的语言模型能否担任大脑。他们让同为 GPT-4 驱动的 InteRecAgent 和用户模拟器交互，做成工具计划的模仿数据集，再微调 LlaMA 2，得到 RecLlama。正文称 RecLlama 作为推荐智能体核心，超过了若干更大的模型。贡献四条：用三组传统推荐工具把交互推荐做成紧凑的 LLM 智能体；针对推荐场景补上候选总线、长短用户画像、动态示例增强的 plan-first，以及反思；用 GPT-4 模仿数据微调出 70 亿参数的 RecLlama；在三个公开数据集上有效，优势在世界知识覆盖较少的领域尤其明显。三个数据集的名字和指标不在本节。

## 2 Related Work

### 2.1 Conversational Recommender System

对话推荐被分成两类。属性问答式系统希望用尽可能少的轮次给出合适物品，交互主要是围绕目标属性提问，逐步收紧兴趣；研究重点是选哪些属性来问，以及探索与利用的权衡。开放对话式系统处理自由格式的对话：早期用预训练语言模型做对话理解和回复生成，后来引入外部知识。作者认为这些方法仍然难以对复杂问询做推理，也难以和用户保持顺畅沟通。LLM 被看成重建对话推荐、补上这些缺口的机会。本节没有实验数字。

### 2.2 Enhancing LLMs

第二条线解释 InteRecAgent 借用的智能体能力从哪来。参数和数据规模上来之后，LLM 出现了上下文学习、指令跟随，以及规划与推理。推荐里使用 LLM 已被说成快速增长的趋势。模型表现出涌现智能后，研究者把 LLM 做成带记忆、规划和工具使用的自主智能体：外部记忆让模型能够积累；规划上，CoT 和 ReAct 用逐步推理，ToT 和 GoT 用多路径推理来保证一致和正确，Self-Refine 和 Reflexion 让模型反思错误后再解题。领域技能则靠外部工具，例如网页搜索、数学工具、代码解释器和视觉模型。本节的定位句是：据作者所知，本文是第一篇在推荐系统里探索「LLM + tools」这一范式的工作。第 2 节到此结束，工具的具体组成和执行细节从第 3 节才展开。

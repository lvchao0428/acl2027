# NoteLLM: A Retrievable Large Language Model for Note Recommendation

## Abstract 摘要

人们喜欢在在线社区中分享包含自身经历的 “notes”（笔记）。因此，推荐与用户兴趣一致的笔记已经成为一项关键任务。现有在线方法只把笔记输入基于 BERT 的模型，以生成笔记嵌入来评估相似度。然而，它们可能没有充分利用一些重要线索，例如代表笔记关键概念的话题标签（hashtags）或类别（categories）。事实上，学习生成话题标签／类别有可能增强笔记嵌入，因为二者都把关键笔记信息压缩进有限的内容。此外，大语言模型（Large Language Models, LLMs）在理解自然语言上已经显著优于 BERT。把 LLM 引入笔记推荐是有希望的。本文提出一个名为 NoteLLM 的新统一框架，利用 LLM 处理物品到物品（item-to-item, I2I）的笔记推荐。具体而言，我们利用 Note Compression Prompt 把一条笔记压缩成单个特殊 token，并进一步通过对比学习方法学习潜在相关笔记的嵌入。此外，我们用 NoteLLM 总结笔记，并通过指令调优自动生成话题标签／类别。在真实场景上的大量验证表明，相对在线基线，所提出方法是有效的，并在小红书（Xiaohongshu）的推荐系统中显示出主要提升。

## 1 Introduction 引言

聚焦用户生成内容（user-generated content, UGC）并提供更真实、更个性化的用户体验，小红书（Xiaohongshu）和 Lemon8 等社交媒体在用户中获得了显著流行。这些平台鼓励用户分享产品评论、旅行博客和生活经历等内容，也称为 “notes”。通过基于用户偏好提供更个性化的笔记，笔记推荐在提升用户参与方面起着关键作用 [16, 34, 48, 64]。物品到物品（I2I）笔记推荐是一种经典方式，用于从百万级笔记池中检索用户可能感兴趣的笔记 [19, 65]。给定一条目标笔记，I2I 方法根据内容 [65] 或协同信号 [19] 选择相关笔记。

I2I 笔记推荐的现有在线方法通常把整篇笔记内容输入基于 BERT 的模型 [3]，以生成笔记嵌入，并基于嵌入相似度推荐相关笔记 [11, 36]。然而，这些方法只是把话题标签／类别当作笔记内容的一个组成部分，没有充分利用它们的潜力。如图 1 所示，话题标签／类别（例如 #Singapore）代表笔记的中心思想，对于判断两条笔记是否包含相关内容至关重要。事实上，我们发现生成话题标签／类别与产生笔记嵌入是相似的。二者都把关键笔记信息压缩进有限的内容。因此，学习生成话题标签／类别有可能提升嵌入质量。此外，大语言模型（LLMs）最近在自然语言 [10, 24, 42, 54] 和推荐 [1, 2, 34, 59] 上展现出强大能力。然而，研究 LLM 在 I2I 推荐中的应用仍然稀少。利用 LLM 改进 I2I 笔记推荐具有相当大的希望。

受上述认识的启发，本文提出一个名为 NoteLLM 的统一多任务方法。基于 LLM，NoteLLM 从 I2I 笔记推荐和话题标签／类别生成任务中学习，旨在通过学习抽取浓缩概念来增强 I2I 笔记推荐能力。具体而言，我们首先为每个笔记样本构造统一的 Note Compression Prompt，然后通过预训练 LLM（例如 LLaMA 2 [42]）解码；这些 LLM 利用一个特殊 token 压缩笔记内容，并同时生成话题标签／类别。为构造相关笔记对，我们从用户行为中统计所有笔记对的共现分数，并为每条笔记形成共现分数集合。我们选择集合中共现分数最高的笔记，作为给定笔记的相关笔记。进一步，为给每个样本推荐相关笔记，生成–对比学习（Generative-Contrastive Learning, GCL）把压缩 token 用作每条笔记的嵌入，然后训练 LLM 从批内负样本中识别相关笔记。同时，我们采用协同监督微调（Collaborative Supervised Fine-tuning, CSFT）方法，训练模型为每条笔记生成话题标签／类别。由于 I2I 笔记推荐任务学到的压缩 token 和话题标签／类别生成任务都旨在抽取笔记内容的关键概念，CSFT 可以有效增强笔记嵌入。

本文做出如下贡献：

- 据我们所知，我们的 NoteLLM 框架是第一个利用 LLM 处理 I2I 推荐任务的。它表明，引入 LLM 是增强 I2I 推荐系统的一种实用且有希望的策略。
- 我们提出一个多任务框架，以学习 I2I 推荐任务和话题标签／类别生成任务来增强笔记嵌入。我们表明，学习生成压缩概念对 I2I 推荐任务是有益的。
- 在小红书的离线实验和在线工业场景上的大量验证，表明我们所提出的笔记推荐技术框架是有效的。

## 2 Related Work 相关工作

### 2.1 I2I Recommendation 物品到物品推荐

I2I 推荐是一项关键技术，能够基于一个目标物品，从大规模物品池中推荐一个有序的物品列表。I2I 推荐要么预先构建 I2I 索引 [55]，要么用近似 k 近邻方法在线检索相关物品 [12]。传统 I2I 推荐通常只依赖来自用户行为的协同信号 [55, 67]。然而，由于缺少用户–物品交互，这些方法无法处理冷启动物品 [65]。为解决这一问题，许多研究考察了基于内容的 I2I 推荐 [8, 65]。我们聚焦于基于文本的 I2I 推荐系统，它根据物品的文本内容衡量相似度。最初，基于文本的 I2I 推荐的表示依赖基于词项的稀疏向量匹配机制 [35, 37]。随着深度学习的出现，神经网络已被证明更擅长表示文本信息 [3, 27]。先前工作 [13, 25, 52, 53] 把文本变换为同一潜在空间中的嵌入，通过嵌入相似度衡量它们的关系。LLM 最近因其令人印象深刻的能力而受到很大关注 [33, 54, 56]。然而，LLM 在 I2I 推荐中的应用仍未被探索。此外，一些研究只把 LLM 当作生成嵌入的编码器 [10, 26, 28]，未能利用其生成方面的全部潜力。在 NoteLLM 中，我们利用 LLM 生成话题标签／类别，这可以增强笔记嵌入。

### 2.2 LLMs for Recommendation 用于推荐的大语言模型

LLM 最近取得了显著进展 [31, 41, 42]。因此，许多研究把 LLM 纳入推荐任务 [5, 18, 50]。把 LLM 与推荐整合主要有三种方法 [18, 50]。第一种方法是利用 LLM 来增广数据 [21, 29, 51]。由于 LLM 包含丰富的世界知识，增广数据比原始数据更突出、更多样 [23, 46, 51]。然而，这些方法需要对测试数据做持续预处理，以与增广后的训练数据对齐，并且高度依赖 LLM 生成的质量。第二种方法是利用 LLM 直接推荐。这些方法设计特殊提示 [9, 20, 43]，或使用监督微调 [1, 2, 59]，以诱导 LLM 回答给定问题。尽管如此，由于上下文长度有限，这些方法只聚焦于重排阶段 [7, 59]，其中只包含数十个候选物品。最后一种方法是把 LLM 用作编码器，生成代表特定物品的嵌入 [15, 49]。虽然这些方法在抽取信息上是有效的，它们都丢弃了 LLM 的生成能力。与上述方法不同，NoteLLM 在召回阶段使用 LLM，并学习话题标签生成，以改善 LLM 产生嵌入的能力。

### 2.3 Hashtag/Category Generation from Text 从文本生成话题标签／类别

话题标签和类别作为社交媒体上的标注机制，简化了对特定主题消息的识别，并帮助用户找到主题内容。从文本生成它们，可以帮助为未标注的笔记创建标识符，或根据用户偏好向用户建议选项。在这一领域，主要有三种方法：抽取式、分类式和生成式。抽取式方法把文本中的关键短语识别为话题标签或类别 [61, 63]，但无法得到原文中不存在的那些。分类方法把该任务视为文本分类问题 [14, 58, 60]。然而，由于人类生成的话题标签多样且形式自由，这些方法可能产生次优结果。生成式方法根据输入文本直接生成话题标签／类别 [4, 44, 45]。不过，这些方法局限于解决话题标签／类别生成任务本身。在 NoteLLM 中，LLM 进行多任务学习，同时执行 I2I 推荐和话题标签／类别生成。由于这两项任务相似，学习生成话题标签／类别也可以增强 I2I 推荐。

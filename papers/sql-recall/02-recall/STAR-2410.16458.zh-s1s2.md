# STAR: A Simple Training-free Approach for Recommendations using Large Language Models

## Abstract 摘要

大语言模型（large language models, LLMs）的近期进展，为推荐系统任务提供了有希望的新途径。当前的最先进方法依赖对 LLM 进行微调来取得最优结果，但这一过程代价高昂，并带来显著的工程复杂度。相反，直接使用 LLM、不再额外微调的方法，推荐质量会大幅下降，原因常常是无法捕捉协同信息（collaborative information）。本文提出 STAR（a Simple Training-free Approach for Recommendation），这是一个利用 LLM 的框架，可以应用于多种推荐任务，无需微调，同时仍保持较高的推荐质量。我们的方法包含一个检索阶段：把来自 LLM 的语义嵌入与协同的用户信息结合起来，以检索候选物品。随后，我们用 LLM 做成对排序（pairwise ranking），以增强下一项预测。在 Amazon Review 数据集上的实验表明，即便只用检索阶段，下一项预测也能取得有竞争力的表现。完整方法相对最佳有监督模型的 Hits@10 为：Beauty 上 +23.8%，Toys & Games 上 +37.5%，Sports & Outdoors 上 -1.8%。该框架为传统有监督模型提供了一种有效的替代，说明 LLM 在无需大量训练或定制架构的情况下，仍有潜力用于推荐系统。

## 1 Introduction 引言

大语言模型（LLMs）的最新进展，为处理推荐任务带来了新机会（Brown et al., 2020; Team et al., 2023; Lin et al., 2023; Zhao et al., 2023; Li et al., 2023b; Chen et al., 2024; Tsai et al., 2024; Wu et al., 2024）。现有方法主要从三种方式利用 LLM：（1）更高级的提示（prompting）（Wang and Lim, 2023; Wang et al., 2023; Hou et al., 2024; Wang et al., 2024b; Xu et al., 2024a; Zhao et al., 2024; Liang et al., 2024）；（2）作为基座模型直接微调（Geng et al., 2022; Zhang et al., 2023; Bao et al., 2023; Xu et al., 2024b; Tan et al., 2024; Kim et al., 2024）；（3）作为特征编码器，用来微调后续的生成模型（Hou et al., 2023; Singh et al., 2023; Rajput et al., 2024; Zheng et al., 2024）或序列模型（Sun et al., 2019; Yuan et al., 2023; Hu et al., 2024）。用提示让 LLM 做打分和排序，能够利用其推理能力，但由于缺少从用户–物品交互中得到的协同知识，这些模型往往明显落后于微调方法。反过来，把 LLM 用于微调——无论是作为基座模型还是特征编码器——都能借助其较强的语义理解来提升模型表现。然而，这需要大量训练和大规模交互数据。

本工作的主要目标，是把 LLM 的语义能力与用户–物品交互数据中的协同知识结合起来，并且不需要额外训练。为此，我们提出使用 LLM 的 STAR（Simple Training-free Approach for Recommendation）框架。STAR 包含两个阶段：Retrieval 与 Ranking。Retrieval 阶段用语义相似度与协同共性的组合，相对用户历史中的物品来为新物品打分。这里我们用基于 LLM 的嵌入来确定语义相似度。此外，时间因子会优先考虑用户最近的交互，评分因子则与用户偏好对齐，以便在特定集合内对物品排序（§3.2）。Ranking 阶段利用 LLM 的推理能力，调整最初检索到的候选的排序。具体而言，我们评估多种基于 LLM 的排序方法，包括 point-wise、pair-wise 和 list-wise，同时也确定 LLM 为更好理解用户偏好并做出准确预测所需要的关键信息（§3.3）。实验评估表明，在多种推荐数据集上，无需有监督训练、也无需开发专门设计的架构，就能取得有竞争力的表现。

我们在 Amazon Review 数据集上给出了大量实验结果（McAuley et al., 2015; He and McAuley, 2016）。发现如下：

1. 检索流水线本身同时包含语义关系与协同信息，相对最佳有监督模型的 Hits@10 为：Beauty 上 +17.3%，Toys & Games 上 +26.2%，Sports & Outdoors 上 -5.5%。
2. 我们表明，pair-wise 排序能在检索表现之上进一步提升，而 point-wise 与 list-wise 方法难以取得类似提升。
3. 我们说明，协同信息是一个关键组成部分，在检索和排序两个阶段都能在语义信息之外带来额外收益。

这些发现表明，有可能构建一个利用 LLM、且无需额外微调的推荐系统，它能显著缩小与完全微调系统之间的质量差距，并且在许多情况下甚至取得更高的质量。

## 2 Related Works 相关工作

近期研究从三条主要途径探讨 LLM 在推荐系统中的作用：（1）用提示做打分和排序；（2）作为基座模型进行微调；（3）作为特征编码器。

### LLM prompting for scoring and ranking. 用 LLM 提示做打分与排序

LLM 可以通过理解以自然语言表达的用户偏好或历史交互来生成推荐。这通常通过生成式选择提示（generative selection prompting）实现：模型从给定候选集中排序并选出顶部物品（Wang and Lim, 2023; Wang et al., 2023; Hou et al., 2024; Wang et al., 2024b; Xu et al., 2024a; Zhao et al., 2024; Liang et al., 2024）。另一条工作线采用排序提示（ranking prompting）（Dai et al., 2023），其灵感来自信息检索中基于 LLM 的排序（Zhu et al., 2023; Wang et al., 2024a），使用 point-wise（Liang et al., 2022; Zhuang et al., 2023）、pair-wise（Qin et al., 2024）或 list-wise（Sun et al., 2023; Qin et al., 2024）方法。然而，如果没有一个检索阶段预先选出供打分和排序的候选物品，仅靠 LLM 提示会因缺少来自用户–物品交互数据的协同知识，而不如微调模型有效。因此，许多方法用微调模型做候选检索，再用 LLM 做排序。不过在这种设置下，整体表现主要由检索质量决定，而不是由 LLM 本身决定。

### LLM as base model for fine-tuning. 把 LLM 作为微调的基座模型

为了把协同知识与 LLM 的语义理解结合起来，近期研究探索了使用用户–物品交互数据进行微调。这能提升推荐表现，但需要大量训练和大规模交互数据集（Geng et al., 2022; Zhang et al., 2023; Bao et al., 2023; Xu et al., 2024b; Tan et al., 2024; Kim et al., 2024）。

### LLM as feature encoder. 把 LLM 作为特征编码器

LLM 也可以用作文本编码器，从物品元数据和用户画像中捕捉更丰富的语义信息（Reimers and Gurevych, 2019; Cer et al., 2018; Ni et al., 2021; Lee et al., 2024）。为进一步优化这些表示，研究者探索了若干途径：（1）用向量量化把连续的 LLM 嵌入映射为离散 token，再训练后续的生成模型（Hou et al., 2023; Singh et al., 2023; Rajput et al., 2024; Zheng et al., 2024）；（2）用 LLM 嵌入初始化嵌入层，再训练序列模型（Sun et al., 2019; Yuan et al., 2023; Hu et al., 2024）；（3）训练模型直接计算物品嵌入与用户嵌入（即用户所选物品的嵌入）之间的相关性（Ding et al., 2022; Hou et al., 2022; Gong et al., 2023; Li et al., 2023a; Liu et al., 2024; Li et al., 2024; Ren et al., 2024; Sheng et al., 2024）。

在本工作中，我们通过整合来自用户–物品交互数据的协同知识，把 LLM 同时用作特征编码器和排序函数。我们发现，LLM 嵌入可以作为有效的物品表示，在无需大量优化的情况下，于序列推荐任务中取得强结果。这与（Harte et al., 2023）一致，但不同之处在于我们使用了同时纳入协同信息与时间信息的新打分规则。

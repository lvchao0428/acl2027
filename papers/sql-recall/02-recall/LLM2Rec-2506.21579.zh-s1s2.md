# LLM2Rec: Large Language Models Are Powerful Embedding Models for Sequential Recommendation

## Abstract 摘要

序列推荐旨在通过建模相似用户或物品历史行为中的协同过滤（collaborative filtering, CF）信号，来预测用户未来的交互。传统序列推荐器主要依赖基于 ID 的嵌入，这些嵌入通过高阶共现模式捕捉 CF 信号。然而，这些嵌入只依赖过去的交互，缺少可迁移的知识，因而难以泛化到未见领域。大语言模型（large language models, LLMs）的近期进展推动了基于文本的推荐方法，它们从文本描述中得到物品表示。这些方法虽然增强了泛化能力，却未能编码 CF 信号，即潜在的物品相关性与偏好模式，而这些对有效推荐至关重要。我们认为，理想的嵌入模型应当把 CF 信号与丰富的语义表示无缝整合，从而同时改善域内（in-domain）与域外（out-of-domain）的推荐表现。

为此，我们提出 LLM2Rec，一种面向序列推荐的新型嵌入模型，把 LLM 丰富的语义理解与对 CF 的感知结合起来。我们的方法采用两阶段训练框架：（1）协同监督微调（Collaborative Supervised Fine-tuning），使 LLM 能够根据历史交互推断物品关系；（2）物品级嵌入建模（Item-level Embedding Modeling），把这些专用 LLM 提炼成同时编码语义信息与协同信息的结构化物品嵌入模型。在真实数据集上的大量实验表明，LLM2Rec 能有效提升域内与域外设定下的推荐质量。我们的发现凸显了利用 LLM 构建更稳健、可泛化的序列推荐嵌入模型的潜力。代码见 https://github.com/HappyPointer/LLM2Rec。

## 1 Introduction 引言

序列推荐旨在通过学习高质量的物品表示来预测用户未来的交互，这些表示应有效捕捉用户偏好模式与物品固有内容 [41, 60]。传统序列推荐器通常为物品分配唯一标识符（ID），并基于历史用户交互序列学习相应表示 [12, 15, 43, 44, 57, 64]。这些基于 ID 的表示主要通过建模序列轨迹中的多跳共现模式来编码 CF 信号 [10, 51]。尽管有效，这类推荐器缺少物品内容信息，因而高度依赖特定领域，无法泛化到未见物品或新领域 [59, 60, 65]。我们认为，序列推荐系统中高质量的物品表示必须同时包含物品语义与 CF 信号。

LLM 的近期进展激发了大量研究，利用丰富的语义信息来改进物品表示学习，包括纯文本表示 [14, 22, 41]，以及融合语义与 CF 信号的混合表示 [13, 30, 40]。纯文本推荐器从预训练语言模型中抽取物品表示，泛化能力强，但忽视了 CF 信号。为缓解这一局限，混合方法试图通过多种融合策略同时整合语义与 CF 信号，包括直接拼接基于 ID 的表示与语义表示 [45, 54, 60]、用内容特征指导基于 ID 的表示学习 [40, 53]、采用混合融合架构 [29, 30]，以及调节嵌入模型以桥接 CF 空间与语义空间 [13, 39]。然而，基于融合的技术，无论是简单拼接，还是交叉注意力（cross-attention）这类复杂机制，都难以学到统一的表示空间，从而导致物品语义与用户行为空间错位。我们认为，为序列推荐开发一种通用嵌入模型——它从本质上同时捕捉 CF 知识与语义知识——是一条更有前景、却尚未充分探索的研究方向。尽管近期工作试图通过对比预训练构建统一嵌入模型，使物品语义与用户行为空间对齐 [13, 39]，这些方法通常需要大规模训练样本，以及大到难以承受的批大小，才能有效编码 CF 信号。更关键的是，它们未能充分利用最先进 LLM 强大的语义理解与推理能力，例如 Qwen [58] 和 Llama [46]。这促使我们研究如何改造 LLM，使其成为可泛化的推荐嵌入模型。

为开发一种对未见领域具有强泛化能力的推荐专用嵌入模型，我们希望把 LLM 强大的语义理解能力与捕捉 CF 信号的能力结合起来。近期研究表明，LLM 可以通过监督微调有效学习推荐任务 [1, 2, 6, 25, 28, 62]。受此启发，我们利用这一途径，使 LLM 感知来自用户交互序列的 CF 信号。为进一步推动 LLM 从 token 级预测转向物品级嵌入生成 [3, 18]，我们通过额外的物品级嵌入建模，把具备 CF 感知的 LLM 提炼为结构化的推荐嵌入模型。

为此，我们提出 LLM2Rec，一种建立在显式感知 CF 信号的 LLM 之上的推荐嵌入模型。具体而言，训练框架包含两个阶段：（1）协同监督微调（Collaborative Supervised Fine-Tuning, CSFT）；（2）物品级嵌入建模（Item-level Embedding Modeling, IEM）。第一阶段，CSFT 在六个真实推荐数据集的混合数据上微调 LLM，要求模型根据历史交互序列预测下一个物品。如图 1 所示，任天堂（Nintendo）系列中若干游戏的嵌入起初是分散的。由于偏好相似的用户经常同时购买这些游戏，经过 CSFT 后，它们的嵌入变得紧密聚集。这一变化表明，LLM 通过 CSFT 学会了捕捉 CF 信号。第二阶段，我们启用双向注意力，并配合掩码下一 token 预测（Masked Next Token Prediction, MNTP），同时施加物品级对比学习，以进一步促使 LLM 成为嵌入模型。双向注意力能够捕捉物品标题内部的上下文化信息 [3]，MNTP 则帮助 LLM 适应新引入的双向注意力掩码。物品级对比学习把预训练目标从 token 级显式转移到物品级，有助于生成可区分的物品嵌入，同时仍保留 CF 信号。MNTP 与物品级对比学习都是轻量适配，计算开销很小，同时仍然有效。如图 1 所示，Nintendo 游戏的嵌入保持接近，同时变得更加可区分，从而为推荐提供更丰富、更有效的信息。

为评估 LLM2Rec 的有效性，我们使用多种下游序列推荐器，在域内与域外数据集上进行了大量实验。实验结果表明，LLM2Rec 在域内与域外数据集上均持续优于现有嵌入模型。此外，在跨越多种类别的混合数据集上训练，有助于提升该嵌入模型的泛化能力。这些发现凸显了 LLM 作为序列推荐中内在强大的嵌入模型的潜力。

## 2 Related Work 相关工作

本节从两个主要类别简要回顾与本文相关的工作：1）序列推荐；2）嵌入模型。

### 2.1 Sequential Recommendation 序列推荐

序列推荐学习物品表示，用以预测用户未来可能交互的物品。从物品表示学习的角度看，现有方法可大致分为三种范式：基于 ID 的方法、纯文本方法，以及 ID 与文本混合的方法。

基于 ID 的方法为每个物品分配唯一标识符，并借助多种序列建模技术学习相应表示，例如循环神经网络 [12]、卷积神经网络 [44]，以及基于 Transformer 的架构 [15, 64]。借助这些技术，基于 ID 的方法从用户交互序列中捕捉物品相关性与用户兴趣。尽管有效，这些方法无法处理来自未见领域或未见物品的任务，缺乏泛化能力。

纯文本方法用从物品内容（例如标题或简介）导出的文本嵌入来表示物品，并以预训练语言模型作为文本编码器。在统一的语言空间中，这些方法有潜力泛化到未见领域 [14, 22, 41]。然而，由于它们严重依赖文本嵌入，其有效性在很大程度上受所采用嵌入模型的限制。此外，这些预训练语言模型面向通用语言任务，而不是专门面向推荐，因此表现也不理想。

ID–文本混合方法通过同时纳入 ID 信息与文本信息来生成表示。常见技术包括：（1）用文本嵌入指导或增强 ID 表示的学习 [27, 29, 40, 52, 53, 56]；（2）拼接文本嵌入与 ID 嵌入 [31, 45, 54, 60]；（3）通过注意力架构融合 ID 与文本信息 [30]。这些方法虽然利用文本信息改进表示学习，但仍依赖基于 ID 的嵌入，表明其有效性仍然高度依赖于在特定数据集上的训练。因此，与纯基于 ID 的方法类似，混合方法必须在目标领域上训练才能学到有效表示，从而限制了它们泛化到新领域的能力 [59, 60, 65]。

### 2.2 Embedding Models 嵌入模型

预训练嵌入模型在多种下游任务中起着基础作用，包括信息检索 [16, 26, 34]、文本相似度 [4] 和分类 [7, 11]。现有方法可大致分为两大类：1）带双向注意力的语言编码器模型；2）基于 LLM 的嵌入模型。长期以来，语言编码器模型一直是学习文本嵌入的主导方法。这些模型采用带双向注意力的 Transformer 架构，从而能够捕捉更丰富的上下文关系，并产生更有效的句子嵌入 [17, 20, 32]。它们的训练目标包括下一句预测 [17]、掩码语言建模 [17, 32]，以及对比学习技术 [8, 23, 38, 49]；后者因在产生高质量句子嵌入方面的有效性而大为流行。随着大语言模型能力不断增强，基于 LLM 的嵌入方法也日益流行。直接的做法是从仅解码器（decoder-only）LLM 的最后隐藏状态生成句子嵌入：要么使用 EOS token 的隐藏状态，要么对句子中全部 token 的隐藏状态做平均池化 [35, 42, 50]。然而，若不经额外训练就直接把预训练 LLM 用作嵌入模型，效果并不理想，因为它们被优化用于预测未来 token，而不是生成整体的句子表示。为应对这一局限，近期方法着重通过进一步适配，把 LLM 改造成专用嵌入模型 [3, 18, 19, 21, 24, 36]。常见技术包括句子级对比学习，以及对注意力掩码的修改；二者都能增强 LLM 作为嵌入模型的有效性。

在推荐任务中，物品之间的隐式关系（即 CF 信号）与语义理解同样重要。面向推荐的有效嵌入模型应当同时整合二者，以最大化表现。尽管大多数序列推荐器依赖通用嵌入模型，已有一些初步工作尝试开发推荐专用嵌入。Blair [13] 使用对比学习，在来自 Amazon 平台、覆盖 33 个类别的超过 30 million 条实例上，把用户评论的表示与物品标题对齐。EasyRec [39] 把用户表示与其交互过的物品对齐，并进一步在对比学习中纳入多样的用户画像与物品画像。然而，由于对比学习的计算成本很高，需要大批量以及足够的训练迭代，这两种方法都把骨干嵌入模型限制在 BERT [17] 或 RoBERTa [32] 这类较小的模型上。最近，LLMEmb [29] 借助大语言模型来扩展推荐专用嵌入模型。它采用属性级增强，并对同一物品的增强视图进行对齐，以增强所生成的嵌入。LLMEmb 主要把 LLM 当作强大的语义编码器，并未把 CF 信号显式整合进所学嵌入。与之不同，我们的方法通过协同监督微调把 CF 信号融入 LLM。再借助随后的轻量物品级嵌入适配，LLM2Rec 在保持计算效率的同时，得到更优的推荐专用嵌入。

# EAGER: Two-Stream Generative Recommender with Behavior-Semantic Collaboration

## Abstract 摘要

生成式检索最近成为序列推荐的一条有希望的途径，它把候选物品检索表述为自回归序列生成问题。然而，现有生成式方法通常只关注物品信息的行为侧面或语义侧面之一，忽略了二者的互补性，因而效果有限。为解决这一局限，我们引入 EAGER，一个把行为信息与语义信息无缝整合的新生成式推荐框架。具体而言，我们指出把这两类信息结合起来的三个关键挑战：一个能够处理两类特征的统一生成架构；保证每一类都得到充分且独立的学习；以及促成细微交互，以增强对协同信息的利用。为实现这些目标，我们提出：（1）一种双流生成架构，利用共享编码器和两个分开的解码器来解码行为 token 与语义 token，并配合基于置信度的排序策略；（2）一个带摘要 token 的全局对比任务，以实现对每一类信息的判别式解码；（3）一个语义引导的迁移任务，通过重构与估计目标来隐式促进交叉交互。我们在四个公开基准上验证 EAGER 的有效性，表明它相对现有方法具有更优表现。源代码将在 PapersWithCode.com 上公开。

## 1 Introduction 引言

推荐系统是管理信息过载的广泛采用的方案，旨在从大规模物品语料中识别用户感兴趣的物品。现代推荐系统通常把表示学习与搜索索引构建整合起来，以改进匹配过程。首先，用双塔架构 [31, 33] 和序列推荐模型 [14, 27] 等模型，把用户和物品编码到共享潜在空间中的潜在表示。随后，为高效地为用户检索 top-k 物品，用 Faiss [13] 和 SCANN [8] 等工具构建近似最近邻（approximate nearest neighbor, ANN）搜索索引。尽管进展显著，表示学习与索引构建这两个分开的阶段常常独立运作，给实现端到端优化带来挑战，从而限制了推荐系统的整体效果 [29]。

为解决这一局限，已有许多研究努力。一个突出方向是构建基于树的匹配索引 [7, 41, 42]，同时优化匹配模型和物品的树结构索引。然而，这些方法常常面临挑战，例如由于树结构导致的推理效率低，以及对物品语义信息的利用有限 [7, 26]。最近，生成式检索 [16] 作为信息检索的一个有希望的新范式出现，并最近被用于生成式推荐 [23]。与传统的基于表示的用户–物品匹配方法不同，这一范式采用端到端生成模型，以自回归方式直接预测候选物品标识符。具体而言，这些方法首先把每个物品 \(x\) 切分成一组离散语义码\(^{1}\) \(C=\{c_1,c_2,\ldots\}\)，然后利用编码器–解码器模型（例如 Transformer [30]）作为检索的端到端索引。在这一设置中，编码器编码用户与物品之间的交互历史 \(\{x_1,x_2,\ldots,x_{t-1}\}\)，解码器预测下一项物品 \(x_t\) 的码序列 \(C_t\)。整体框架如图 1 所示。

然而，现有生成式推荐方法在如何利用物品信息上有一个显著缺点，常常狭窄地只关注行为侧面或语义侧面。行为信息来自用户–物品交互历史，而语义信息涵盖物品的文本或视觉描述。例如，RecForest [7] 利用预训练的 DIN 模型 [38] 抽取基于行为的物品嵌入来构造语义码，而 TIGER 利用 Sentence-T5 模型 [21] 从文本描述中导出基于语义的物品嵌入。然而，这些方法常常只专注于一个侧面，忽略了行为与语义之间的互补关系。一方面，BERT [4] 和 ViT [6] 等预训练模态编码器的进展促进了多模态特征的整合，增强了先验知识，并在多模态推荐模型中得到广泛应用 [18]。另一方面，行为数据通过交互序列捕捉用户特定的偏好，因而在推荐语境中特别有效。反过来，语义信息提供关于物品特征的更广泛、无偏的认识，有利于跨不同领域更好地泛化。

本文提出 EAGER，一个带有行为–语义协作的新型双流生成式推荐器（two-strEAm GEnerative Recommender）。我们分析在统一生成框架中建模行为与语义的挑战，并从以下三个方面加以应对。

第一，一个用于处理两类不同信息的统一生成架构至关重要。鉴于行为与语义的特征空间存在固有差异，像先前双塔模型 [25, 34] 所表明的那样，在编码器侧通过特征融合直接整合它们会带来挑战。因此，我们的方法为行为和语义分别构造码，采用双流生成架构，每一流在解码器侧充当不同的监督信号。该架构包括一个用于编码用户交互历史的共享编码器，以及两个分别预测行为码和语义码的分开的解码器，从而避免过早的特征交互。推理时，我们把每一流的预测熵用作物品排序的置信度度量，以增强两流结果的合并，确保有效预测。

第二，确保充分且独立的学习，对于充分发挥每一类信息的潜在价值至关重要。先前工作 [23] 通常采用自回归方法逐个学习每个 token，关注的是离散和局部信息，而不是捕捉全局认识。在 EAGER 中，我们引入一个带摘要 token 的全局对比任务。该模块的灵感来自两个主要来源：（1）传统双塔模型用对比学习获取有判别力的物品特征。类似地，我们希望解码器模型在自回归生成能力之外，也能掌握全局判别能力，从而在对比范式内增强物品特征的抽取；（2）Transformer 模型 [4, 6] 利用特殊 token 来封装全局信息，这促使我们在 token 序列末尾追加一个摘要 token。该 token 以单向方式总结已累积的知识，并作为蒸馏的焦点。

第三，尽管分开解码和预测重排已经显示出有效性，整合细微的交互可以增强两条知识流的共享。如前所述，直接的特征级交互常常产生次优结果 [34]。因此，我们引入一个精心设计的语义引导迁移任务，以促进隐式的知识交换。具体而言，我们提出语义信息可以引导行为侧面，并设计一个具有双重目标的辅助 Transformer：重构与识别。重构目标是用全局语义特征预测被掩码的行为 token，而识别目标旨在区分一个行为 token 是否与指定的全局语义特征一致。通过这些目标，该模块用 Transformer 模型间接优化行为特征与语义特征之间的交互。

总之，我们的主要贡献如下：

- 我们引入 EAGER，一个以协作方式整合行为信息与语义信息的新生成式推荐框架。
- 我们提出统一的双流生成架构，设计带摘要 token 的全局对比模块以确保充分且独立的学习，并引入语义引导的迁移模块以实现细微交互。
- 在四个公开推荐基准上的大量实验表明，EAGER 优于现有方法，涵盖生成式范式和传统范式。

## 2 Related Work 相关工作

### Sequential Recommendation. 序列推荐

用深度序列模型捕捉推荐系统中的用户–物品模式，已经形成了丰富的文献。GRU4REC [10] 最先把基于 GRU 的 RNN 用于序列推荐。SASRec [14] 采用自注意力，类似于 decoder-only Transformer 模型。受语言任务中掩码语言建模成功的启发，BERT4Rec [27] 把带掩码策略的 Transformer 模型用于序列推荐任务。S\(^3\)-Rec [39] 不仅依赖掩码，还通过四个自监督任务预训练嵌入，以提升物品嵌入和用户嵌入的质量。上述方法主要依赖近似最近邻（ANN）搜索索引（例如 Faiss [13]）来检索下一项。此外，基于树的方法 [7, 41, 42] 在推荐系统中显示出有希望的表现。例如，RecForest [7] 通过创建多棵树来构造一座森林，并整合基于 Transformer 的结构用于路由操作。最近，TIGER [23] 引入了 semantic id 的想法：每个物品被表示为一组从其侧信息导出的 token，然后以 seq2seq 方式预测下一项物品的 token。在本工作中，我们旨在进一步探索一种双流生成架构，作为 top-k 物品检索的端到端索引。

### Generative Retrieval. 生成式检索

生成式检索 [16] 最近被提出作为一种新的检索范式，它包含两个主要阶段：离散语义切分（discrete semantic tokenization）[11, 12, 17] 和自回归序列生成 [23, 29, 32]。在文档检索领域，研究者探索了用预训练语言模型生成多种类型的文档标识符。值得注意的是，DSI [29] 和 NCI [32] 利用 T5 [22] 模型产生层次化文档 ID。反过来，SEAL [1]（以 BART [15] 为骨干）和 ULTRON [40]（使用 T5）利用标题或子串作为标识符。另一种方法 AutoTSG [35] 采用词项集合（term-sets）用于识别。生成式文档检索也扩展到了多个领域。例如，IRGen [37] 用基于 ViT 的模型做图像搜索，而 TIGER [23] 把 T5 用于推荐系统。然而，由于预训练语言模型资源消耗大，这些研究在推荐系统内的大规模物品检索上常常面临挑战。相比之下，本文深入探讨在此类系统中为生成式检索同时整合行为与语义。
